# REMAKE DAY — 첫 플레이 안내

같은 하루를 다섯 번 겪으며, 이곳에서 무슨 일이 일어나는지 이해하는 게임입니다. 화면을 살펴보고 인물과 대화한 뒤, 밤마다 그때까지 이해한 내용을 적어 주세요. 모르는 부분은 모르는 채로 남겨도 됩니다.

1. [게임 시작](http://localhost:3500/play)을 엽니다. 이 주소는 게임 서버를 실행한 컴퓨터에서 사용합니다.
2. 점수에 관계없이 다섯 번째 밤까지 진행합니다. 게임 안에서 제공하는 노트와 질문 기능은 자유롭게 사용합니다.
3. 진행 중에는 같은 탭을 유지하고 새로고침하지 않습니다. 현재 화면은 새로고침 후 이어하기를 지원하지 않습니다.
4. 다섯 번째 밤의 점수 화면에서 잠시 멈추고, 아래 내용을 기록합니다. 이후 계속 진행해 결말과 개발 회고를 확인합니다.

플레이 전에는 공략·개발 문서·다른 사람의 답안을 보지 않습니다. 이미 게임을 했거나 정답을 알고 있다면 진행자에게 알려 주세요. 조작을 모르겠거나 오류가 생기면 도움을 요청해도 됩니다.

마지막 점수 화면에서 남길 내용:

- 최종 점수:
- 이곳에서 어떤 일이 일어났다고 이해했나요?
- 그렇게 생각하게 만든 장면·대화·노트는 무엇인가요?
- 아직 설명되지 않거나 서로 맞지 않는 부분은 무엇인가요?
- 조작이나 기다림 때문에 진행하기 어려웠던 순간이 있었나요?

정답을 맞히는 능력보다 게임이 얼마나 잘 전달되는지를 확인하는 테스트입니다. 원하면 언제든 중단할 수 있으며, 중단한 경우 마지막 회차와 이유를 알려 주세요.
