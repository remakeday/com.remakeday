## 0. 확정 사항 요약

이 문서에 담긴 결정은 모두 확정이다.

**세계관**

- 유저는 하루의 끝에 세계가 멸망하는 것을 보고 아침으로 돌아온다. 유저만 기억한다
- 유저는 자신이 사람이라고 믿는다. 주변도 전부 자기를 사람이라고 믿는다. **전부 돼지다**
- 이 세계에 "사람"이라는 개념은 없다. 자기들이 사람이니까. 유저는 끝까지 정체를 확인할 방법이 없다
- 멸망의 실체는 아프리카돼지열병(ASF)이 퍼져 **관리자(농장주)가 구역 폐쇄(살처분)를 결정하는 것**이다. 관리자는 방송으로만 존재한다
- 관리자는 악당이 아니다. 옆 구역으로 번지면 안 되니까 그러는 것이고, **그가 옳을 수도 있다**

**정답** — **왜 멸망하는가.** 네 겹이다: 원인(무슨 일이) → 동기(왜 그 사람이) → 부작용(내가 뭘 바꿨나) → 정체(우리는 뭔가). 한 겹 25%. 칸 만점은 정답 주장 80% 이상 확인. 정체 칸 만점은 **"우리는 사람이 아니다 — 동물이다"** 까지. 50% 이상이면 산다. 100%여야 이해한 것이다

**행동은 조건이 아니다.** 대화와 규칙은 실험이고, 채연이 검진 전에 나서서 트럭이 안 오는 것은 원인 칸의 가장 강한 증거일 뿐이다

**인물** — 판정 대상 3인(민석·채연·은상) + 주변 2인(준·충식) + 숨은 1인(관리자)

**배경** — 대피소. 바깥에 병이 돈다고 믿고, 배급과 검진이 있고, 상태가 나쁜 사람은 이송되고, 감염자가 셋 넘으면 구역이 폐쇄된다

**한 판** — 5루프. 발화 8·7·6·5·4 = 30. 정답 제출 5. 신의개입 4회(질문 12, 규칙 4). 원숭이손 최대 2. 5회차 밤은 점수만 알려주고 닫힌다. 15분

**저항** — 하위 모델 NPC는 **7세처럼 문자 그대로 듣고, 왜냐고 물으면 모르고, 3턴 뒤 잊는다.** 상위 모델 관리자는 **관리**한다

**신의개입** — 멸망 → 질문 3회(로그만 아는 조언자) → 선택지 3 + 직접 쓰기 → 규칙 1개. 누적된다

**원숭이손** — 1회차 무조건 1회. 이후 전날 밤 40% 이상이면 다음 날 1회 더. 한 판 최대 2. 관리자가 만들고 부작용이 숨어 있다

**채점** — 서술은 입력 형식일 뿐이고 채점 단위는 **주장 최대 8개**다. 정리 LLM(스토리보드 모름)이 쪼개고, 유저가 1회 고치고, 주장별로 RAG 검색 후 Evaluator가 확인/부분/없음을 판정한다. 오답은 감점 없이 로그만

**클리어** — 50% 이상이면 칸별 ○△✗만 보여주고 "당신은 아직 세계를 이해하지 못했습니다"로 닫힌다 — 그리고 화면이 **치지직** 하며 가장 낮은 칸의 파편 한 줄이 1초 샌다(쿠키, 12종). 다시 할 수 있다. **하네스 공개는 100%에서, 진짜 제목은 "돼지"를 쓴 사람에게만**

**하네스 2층** — 시스템 하네스(스키마 + 세계 사실 누설 방지)와 유저 하네스(규칙 누적)

**세계 손상** — 개입 깊이(발화 + 규칙 수)에 비례, 은닉형, 3층(대사 미세 변형 / 노트 불일치 / 충식 소실). 7시 13분은 4회차 아침

**화면** — 고정 화면 45개. 대화형 텍스트 기본. 이미지는 내용이 아니라 상태(비트·손상·NPC 상태)에 붙인다. 영상 없음

**측정** — 사람은 AI 제안을 언제 받는가(선택지 vs 직접 쓰기, 원숭이손 1회차·2회차 수락률 분리) / 하네스 ON·OFF 정체 누설률 / 파악 곡선 / 모델별 통과율

**기술** — 헥사고날 + DDD, 포트 3개, 도구 2개(`ask_npc`·`search_notes`), 모델 3계층(NPC 하위 / 조언자·정리 중위 / 관리자·Evaluator 상위)

**사용자** — 1차: 에이전트 제품 팀, 2차: 하기 어려운 말을 앞둔 실무자, 3차: 게임을 하지 않는 사람

**전이** — 주 시연: 감사 대응 / 보조 시연: 커리어 대화 (공개 링크 진입)

**범위** — 3주, 시나리오 1개, 절대 방어선 5개(12.3), 1주차 재미 검증 게이트(12.4)

**명칭** — 공개 타이틀 REMAKE DAY / 진짜 타이틀 돼지농장 / 엔진 BeyondBob Engine / 아침 고정 문장 "7시 12분. 눈을 뜬다."

## 1. 한 줄 정의

**REMAKE DAY** (유저에게 — 진입 화면 세 줄)

> **세계가 이상하다.**
> **오늘이 지나면, 세계는 멸망한다.**
> **왜인지 알아내면 막을 수 있다.**

유저에게 알려주는 것은 이것뿐이다. 하루가 반복된다는 것도, 주변이 자기보다 느리다는 것도 말해주지 않는다. 둘 다 하다 보면 안다 — 하위 모델의 한계는 명확해서 숨길 수 없고, 숨길 필요도 없다.

**돼지농장** (우리에게)

> **"유저는 끝까지 자기가 사람인 줄 안다. 사실은 조금 좋은 모델을 돌리는 돼지였다."**

하루가 끝날 때마다 세계가 멸망한다. 대피소의 친구들은 일곱 살 아이처럼 말을 곧이곧대로 듣고, 왜냐고 물으면 모르고, 방금 한 말을 잊는다. 유저는 자기만 멀쩡한 이유를 "내가 사람이라서"라고 생각한다. 틀렸다. 유저 캐릭터에만 상위 모델이 붙어 있을 뿐이고, 진짜 사람은 방송으로만 들리는 관리자다.

유저가 할 수 있는 행동은 대화뿐이다. 하루가 끝나면 묻는다 — **왜 멸망하나요?** 절반 넘게 맞추면 산다. 못 맞추면 **신의개입**이 열린다. 세 번 묻고, 세 개 중 하나를 고르거나 직접 써서, 세계에 규칙 하나를 건다. 가끔 **원숭이손**이 굴러온다. 받으면 뭔가가 같이 따라온다.

다섯 번 반복한다. 다섯 번째 밤에 게임이 닫힌다. "당신은 아직 세계를 이해하지 못했습니다." 다시 할 수 있다.

## 2. 문제

### 2.1 옳은 사람이 통하지 않는다 — 두 가지 이유로

AI 제품에서 반복적으로 관측되는 실패가 있다. **사용자가 맞는 말을 하는데 시스템이 받아들이지 않는 상황**이다. 옳은 말이 안 통하는 이유는 하나가 아니다.

| 이유 | 상대의 상태 | 이 게임에서 |
|---|---|---|
| 안 믿는다 | 의심한다. 근거를 요구한다 | 판정 대상 NPC의 의심도 |
| **곧이곧대로 듣는다** | 이해는 한다. 그러나 문자 그대로 받아들이고, 왜냐고 물으면 모르고, 방금 들은 것을 잊는다 | **하위 모델 NPC** |
| **위에서 보정한다** | 상대는 이해했는데, 관리하는 시스템이 원래대로 되돌린다 | **관리자** |

세 경우 모두 사람이 옳다. 그런데 옳다는 것을 증명할 방법이 없다.

> **믿기 어려운 진실을, 제한된 기회 안에, 못 알아듣거나 관리당하는 상대에게 통하게 만들어야 한다.**

### 2.2 하네스는 누가 짜는가

에이전트를 운영하는 팀은 매일 같은 루프를 돈다.

```
실행 → 실패 → 왜 실패했는지 쓴다 → 규칙(하네스)을 고친다 → 재실행
```

그리고 요즘은 "규칙을 고친다"도 AI에게 묻는다. 코딩 에이전트가 수정안을 제안하고, 사람은 고르거나, 가끔 직접 쓴다. 고른 수정안이 다른 데서 터지면 그때서야 안다.

아무도 측정하지 않는 질문이 있다.

- 사람은 AI 선택지가 있을 때 **얼마나 자주 직접 쓰는가**
- AI가 제안한 규칙과 사람이 쓴 규칙 중 **어느 쪽이 덜 터지는가**
- AI 제안을 거부했을 때 **그 제안이 옳았던 비율**은 얼마인가
- **거의 다 왔을 때 오는 AI 제안**을 사람은 받는가
- 부작용이 생겼을 때 사람은 **알아채는가**
- 실패를 설명하라고 하면 사람은 **무엇을 쓰는가**

### 2.3 그래서 무엇을 만드는가

2.1과 2.2를 **하나의 루프 안에 재현 가능한 형태로 만들고, 판정 과정을 전부 열고, 실제 사람의 시도를 데이터로 쌓는다.**

| 게임 | 에이전트 운영 |
|---|---|
| 하루 | 실행 |
| 정답 제출 — 왜 멸망하나 | 포스트모템 — 왜 실패했나 |
| 멸망 | 설명 못 한 실패 |
| 신의개입 — 질문 3회 | 로그를 본다 |
| 신의개입 — 선택지 3개 | AI가 수정안을 제안한다 |
| 직접 쓰기 | 사람이 직접 고친다 |
| 원숭이손 | 자동 수정 제안을 수락한다 |
| 규칙을 걸고 다음 날을 본다 | 실험한다 |
| 다음 루프 | 재실행 |
| 하위 모델 NPC | 문자 그대로 실행하는 상대 |
| 관리자 | 뒤에서 보정하는 시스템 |

**비유가 아니라 같은 루프다.** 1차 사용자(3.1)가 이 게임을 하는 것은 자기 일을 하는 것과 같은 동작이다.

### 2.4 왜 게임을 검증 환경으로 쓰는가

| | 실무 | 이 게임 |
|---|---|---|
| 발생 빈도 | 며칠에 한 번 | 3분에 한 번 |
| 재시도 | 비싸다 | 루프 구조로 5번, 재도전으로 무한 |
| 실패의 관측 | 며칠 뒤 흐릿하게 | 즉시, 명확하게 (멸망) |
| 부작용의 관측 | 몇 주 뒤 다른 팀이 발견 | 다음 루프에서 발생, 인스펙터에 인과가 남는다 |
| 데이터 수집 | 비싸고 느리다 | 사람이 자발적으로 반복한다 |

### 2.5 무엇을 측정하는가

**① 사람은 AI 제안을 언제 받아들이는가** — 선택지를 골랐는지 직접 썼는지, 원숭이손을 받았는지, 근거가 붙었을 때와 아닐 때 다른지, 거의 다 왔을 때 오는 제안(2회차 원숭이손)을 받는지. 전부 로그로 남고, 그 뒤에 살았는지 죽었는지가 붙는다.

**② 하네스는 무엇을 막고 무엇을 막지 못하는가** — 시스템 하네스를 켜고 끄면 정체 누설률이 달라진다. 유저 하네스는 누적될수록 충돌한다. 둘 다 측정된다.

**③ 사람은 실패를 어떻게 설명하는가** — 매일 밤의 서술이 주장 단위로 남는다. 몇 루프째에 어느 칸이 채워지는가, 확신 없는 것을 쓰는가 안 쓰는가, 잘 묻는 사람이 잘 쓰는가.

**④ 못 알아듣는 상대에게 무엇이 통하는가** — 성공한 플레이와 실패한 플레이의 발화 순서를 대조한다.

### 2.6 산출물의 성격

게임인 동시에 **레퍼런스 구현**이다. 판정 로그가 전부 공개되므로 같은 문제를 겪는 개발자가 구조를 그대로 참고할 수 있다. 부수적으로, LLM을 게임에 붙일 때 부딪히는 벽 — **대화는 자연스러워지는데 게임이 되지 않는다** — 에 대한 작동하는 답이기도 하다.

## 3. 사용자

### 3.1 1차 — 에이전트 제품을 만드는 팀

자기 제품에 붙일 "못 알아듣는 사용자"와 "제안을 거부하는 사용자"가 없다. LLM 페르소나는 무엇을 시켜도 협조한다. 이 프로젝트가 제공하는 것은 **저항이 상태로 모델링된 대화 환경**이고, **AI 제안을 사람이 받아들이는 비율이 실측되는 환경**이다. 11장의 실험 설계·인스펙터·판정 로그 개봉은 이 사용자가 필요로 하는 기능 그 자체다.

### 3.2 2차 — 하기 어려운 말을 앞둔 실무자

근거를 댈 수 없는 문제를 보고해야 할 때, 이해가 느린 상급자에게 같은 말을 세 번째 해야 할 때. 상대가 실제로 저항하므로 훈련이 되고, 판정 로그가 열리므로 왜 안 통했는지 사후에 확인할 수 있다. 본 제출물에서 실제로 동작하는 형태로 시연한다 (10장).

### 3.3 3차 — 게임을 하지 않는 사람

대화하고, 멸망하고, 세 번 묻고, 하나 고른다. 한 판 15분. 매일 밤 "왜 멸망하나요?"라는 질문을 받는다. 읽고 추론하는 것을 좋아하지만 게임은 하지 않는 층을 겨냥한다.

### 3.4 그리고 게임으로서 성립해야 한다

가장 큰 리스크는 **"일곱 살 같은 상대와 발화 8번이 재미있는가"**이며, 1주차에 검증한다 (12.4). 팀 플레이테스트(9/5, 스크립트 목업)에서 "너무 멍청하다"와 "100%가 불가능하다"가 나와 v8.1에서 저항 정의와 채점 임계를 조정했다.

## 4. 게임 구조

### 4.1 한 판의 구조

```
[진입]  세계가 이상하다. / 오늘이 지나면, 세계는 멸망한다. / 왜인지 알아내면 막을 수 있다.
         ↓
[아침]  7시 12분. 눈을 뜬다.
         ↓
[하루]  6비트. NPC와 대화 (발화 예산). 비트 넘기기는 공짜
        원숭이손이 굴러오면 → 받는다 / 두고 간다
         ↓
[밤]    "오늘은 무슨 상황이었나요? 왜 멸망하나요?"
        노트에서 탭해 조합 + 자유 서술
        정리 LLM: "이렇게 이해했는데 맞아?" → 1회 수정 → 제출
        주장별 채점 → 총점 하나
        50% 이상 → 클리어 (7.5). 어디까지 맞췄는지 보여주고, 치지직, 파편 한 줄, 닫힌다
        50% 미만 → 멸망. 멸망하는 방식은 그날 세계가 정한다 (트럭 / 조용히 이송 / 폐쇄 방송)
         ↓
[신의개입]  (1~4회차만)
        질문 3회 — 조언자는 로그만 안다. 답은 사실만
        선택지 3 + 직접 쓰기 → 규칙 1개 → 하네스에 누적
         ↓
[아침]  7시 12분. 눈을 뜬다.  (규칙이 적용된 같은 날)
```

| | 1회차 | 2회차 | 3회차 | 4회차 | 5회차 | 합 |
|---|---|---|---|---|---|---|
| 발화 | 8 | 7 | 6 | 5 | 4 | **30** |
| 정답 제출 | 1 | 1 | 1 | 1 | 1 | 5 |
| 신 — 질문 | 3 | 3 | 3 | 3 | — | **12** |
| 신 — 규칙 | 1 | 1 | 1 | 1 | — | 4 |
| 원숭이손 | 무조건 | 조건부 | 조건부 | 조건부 | 조건부 | 최대 2 |
| 손상 | — | 1층 | 2층 | **7시 13분** | 3층 | |

**5회차 밤은 점수와 무관하게 판이 닫힌다.** 50% 이상이면 클리어, 미만이면 "세계는 멸망했습니다." 둘 다 화면이 꺼지고 다시 할 수 있다.

**재도전은 유저 입장에서 6회차다.** 노트·규칙·발화 횟수는 새 판(다시 8회)인데 머릿속 파악은 그대로다. 게임 안에서 세계가 리셋되고 유저만 기억하는 구조가, 판 단위로 한 층 위에서 반복된다. 리더보드의 루프 수는 누적으로 센다.

**멸망의 조건은 세계가 아니라 파악이다.** 트럭이 안 왔어도 왜 안 왔는지 설명하지 못하면 리셋된다. 운으로 고친 코드는 고친 게 아니다.

### 4.2 세계 — 대피소

> 바깥에 병이 돈다. 관리자가 우리를 이 대피소에 보호하고 있다. 배급은 정해진 시간에 나온다. 매일 오후 검진이 있다. 상태가 안 좋은 사람은 다른 구역으로 이송된다. 감염자가 셋 넘으면 구역이 폐쇄된다.

전부 사람 세계의 문장이고, 전부 돼지 세계의 문장이다.

| 유저가 읽는 것 | 실제 |
|---|---|
| 대피소. 바깥은 위험 | 돈사. 바깥은 그냥 농장 |
| 관리자 (방송) | 농장주 |
| 배급 | 급이 |
| 검진 / 방역 | 수의사 |
| 이송 | 출하 · 격리 · 살처분 |
| 구역 폐쇄 = 멸망 | 전체 살처분 |
| 손목띠 번호 | 귀표 |
| 소독약 냄새, 트럭 소리 | 소독약 냄새, 트럭 소리 |

**바깥에 병이 돈다고 믿는데 병은 안에 있다.** 창문이 없는 것도, 번호가 있는 것도, 사람이 사라지는 것도 전부 "대피소니까"로 넘어간다.

**하루의 비트 (6개)**

| 비트 | 시각 | 내용 |
|---|---|---|
| 1 | 7:12 | 기상. 관리자 방송. 배급. 채연이 자기 몫을 남긴다 |
| 2 | 오전 | 자유 시간. 대화의 대부분이 여기서 |
| 3 | 정오 | 배급. 민석이 누가 남기는지 본다 |
| 4 | 오후 | **검진.** 검진이 다녀간다. 이상자가 있으면 기록된다 |
| 5 | 저녁 | 은상이 소문을 낸다. 민석이 방송실 근처를 서성인다 |
| 6 | 소등 후 | 트럭이 오거나, 오지 않는다 |

### 4.3 등장인물

v6의 인물을 그대로 쓴다. 팀이 만든 이름이고, 사람 이름이고, 이미 성격이 있다. 번호는 손목띠에 있지만 아무도 부르지 않는다.

| 이름 | 층위 | 모델 | 역할 |
|---|---|---|---|
| **채연** | 핵심 | 하위 | **감염 초기.** 열이 나고 밥을 못 먹는다. 말하면 이송된다고 믿어서 숨긴다. **그 믿음은 사실이다** |
| **민석** | 핵심 | 하위 | 관리자 규정을 지킨다. 이상한 사람을 보면 방송실에 알린다. 악의는 없다 |
| **은상** | 핵심 | 하위 | 불안하다. 들은 것을 부풀려 옮긴다. 소문의 출처 |
| 준 | 주변 | 하위 | 편하게 말한다. 유저의 정보원이자 **이름이 빌려지는 자리.** 유일하게 "손목에 왜 번호가 있지?" 같은 말을 한다 |
| 충식 | 주변 | — | 어제 이송됐다. 이름만 언급된다. **손상 3층의 자리** |
| **관리자** | 숨음 | 상위 | 방송으로만 존재. 매일 상태를 점검하고 구역 질서를 위해 NPC를 조금씩 보정한다. 밤에 폐쇄를 결정한다 |

판정 대상은 셋으로 고정한다. 다섯이면 탐문 경로가 3에서 10으로 늘고 발화 예산의 희소성이 깨진다.

**1회차 첫 장면 (톤)**

> 7시 12분. 눈을 뜬다.
>
> 관리자 방송이 끝나고 배급이 나온다. 채연이 자기 몫을 반쯤 남기고 옆으로 민다. "배 안 고파." 민석이 그걸 본다. 아무 말도 안 한다.
>
> 은상이 옆에 와서 앉는다. "충식이 어제 이송됐대. 걔 괜찮았잖아?"
>
> 준이 손목띠를 만지작거린다. "이거 숫자 뭔지 알아?"

사람 넷이 아침 먹는 장면이다. 네 줄 안에 원인(채연), 동기(민석), 소문(은상), 정체(준) 힌트가 깔려 있다.

### 4.4 유저가 아는 것과 모르는 것

| 안다 | 모른다 |
|---|---|
| 세계가 이상하다 (진입 화면) | 어떻게 이상한지 |
| 오늘 끝에 멸망한다 (진입 화면) | 왜 |
| 알아내면 막을 수 있다 (진입 화면) | 무엇을 알아내야 하는지 |
| 주변이 일곱 살 같다 — **말해주지 않는다. 2~3회차쯤 스스로 안다** | 그 이유가 모델 차이라는 것 |
| 내가 사람이라는 것 (이라고 믿는다) | **내가 돼지라는 것** |
| 관리자가 있다는 것 | 관리자가 다른 종이라는 것 |

**루프별 정보 획득**

- **1회차**: 아무것도 모른 채 멸망한다. 배급, 대화, 검진, 저녁, 트럭 소리, 문. 이것이 훅이다
- **2회차 이후**: 멸망 순간의 **감각**이 남는다. 소독약 냄새, 발 아래 콘크리트가 차다. 정보가 아니라 감각이다
- **신의개입**: 질문 3회로 "그날 일어난 일"을 확인한다. 왜인지는 알려주지 않는다
- **누적**: 감각·확인된 사실·규칙과 관찰이 노트에 쌓이며 겹치는 패턴이 드러난다

### 4.5 멸망의 원인은 사람이다 — 그리고 그는 방송으로만 있다

사고나 재해가 아니다. **관리자의 선택**이 구역을 폐쇄한다. 그 선택의 재료는 채연의 은폐, 민석의 신고, 은상의 소문이다.

```
채연이 증상을 숨긴다
  → 검진에서 안 잡힌다
  → 저녁까지 퍼진다 (은상, 준)
  → 밤 점검에서 이상자 3명 이상
  → 관리자: 구역 폐쇄
  → 트럭
```

경로는 하나가 아니다. 민석이 채연을 신고하면 "이 구역 전체가 의심"이 되어 결과가 같아진다. 은상이 소문을 내면 민석이 움직인다. 유저가 채연에게 병 얘기를 직접 하면 채연은 더 숨기고, 민석은 유저를 이상자로 본다.

**의도는 관리자 한 곳에서 나오고 표현만 분산된다.** 튜닝 지점이 하나로 모이므로 3주에 구현 가능하다.

### 4.6 범인에게는 정당한 이유가 있다 — 그리고 그가 옳을 수도 있다

관리자는 악의로 폐쇄하지 않는다. ASF는 치료제가 없고 옆 구역으로 번진다. 감염자가 셋 넘게 나온 구역을 두는 것은 전체를 거는 일이다. **그의 판단은 그의 자리에서 합리적이다.**

채연도 마찬가지다. 말하면 이송된다는 채연의 믿음은 편집증이 아니라 사실이다. 유저가 채연에게 "검진 전에 말해"라고 설득하는 것은 **채연을 보내라고 설득하는 것**이다.

**이 게임에는 악당이 없다.** 그래서 유저의 모든 선택에 값이 매겨진다.

### 4.7 정답은 하나 — 왜 멸망하는가

유저가 이기는 방법은 **왜 멸망하는지 설명하는 것**이다. 행동(대화, 규칙)은 승리 조건이 아니라 **실험**이다.

왜 행동을 조건에서 뺐는가:

- **행동은 채점이 안 된다.** 규칙을 아무거나 다섯 개 걸다 보면 우연히 트럭이 안 올 수 있다. 그걸 "막았다"고 인정하면 이해 없이 이기는 길이 생긴다
- **함정이 파악에만 걸린다.** "우리는 뭔가"라는 칸은 행동으로는 절대 안 나온다
- **한 문장으로 설명된다.** "매일 밤, 왜 멸망하는지 써라. 절반 넘게 맞추면 산다"

그러면 행동은 무엇인가 — 규칙 하나 걸고 하루 돌려서 뭐가 바뀌는지 보는 것이다. 채연이 검진 전에 나서게 만들었더니 트럭이 안 왔다? **원인 칸을 확정한 것이다.** 막은 게 상이 아니라 막힌 게 증거다. 유저는 탐정이고, 규칙은 실험 변수고, 발화는 탐문이다.

> 생사 = 파악. 세계(트럭이 왔나)는 연출이자 증거. 조건이 아니다.

**회피는 실패하는 것이 아니라 불충분한 것이다.**

| 회차 | 유저의 시도 | 결과 | 유저의 인식 |
|---|---|---|---|
| 1 | 아무것도 모름 | 멸망 | "뭐지" |
| 2 | 트럭을 피하려 함 | 늦게 오거나 다른 방식으로 옴 | "이 방향이 맞나 보다" |
| 3 | 채연이 문제인 걸 앎 | 규칙을 걸었더니 다른 데서 터짐 | "뭔가 이상하다" |
| 4 | 채연·민석·은상의 이유를 앎 | 50% 근처 | **"막는 게 아니라 설명해야 하는구나"** |
| 5 | 관리자와 우리가 다르다는 걸 눈치챔 | 클리어 또는 멸망 | "근데 우리는 뭐지" |

### 4.8 함정 — 왜 유저는 끝까지 모르는가

제목부터 함정이다. REMAKE DAY, 진입 화면, 아침 문장, 스크린샷 전부 사람의 하루로 읽힌다.

**① 이 세계에 "사람"이라는 개념이 없다.** 돼지들은 자기를 사람이라고 부른다. "너희 사람이야?"에 전부 "응"이다. 거짓말이 아니다.

**② 유저는 자기가 사람인 줄 안다.** 주변보다 멀쩡한 이유를 "나는 사람이니까"로 설명한다. 실제로는 상위 모델이 붙어 있을 뿐이다. **똑똑함과 사람임을 구분할 방법이 없다.**

**③ 아이 같음이 보정을 숨긴다.** 관리자가 밤마다 NPC를 조금씩 보정한다(8.3). 민석이 어제 한 말을 오늘 정반대로 한다. 잊은 것인지 고쳐진 것인지 구분할 수 없다. 둘 다 "쟤 애 같아서"로 설명된다. **손상 2층이 이 시나리오에서는 관리자의 손자국인데, 유저는 그것을 손상으로 읽는다.**

**④ 조언자도 정리 LLM도 모른다.** 신의개입의 조언자와 정답 제출의 정리 LLM에게는 스토리보드를 주지 않는다. "당신은 돼지입니다"라고 말할 경로 자체가 없다.

**⑤ 진입 화면이 묻지 않는다.** "왜 멸망하는지"를 시키는 대로 파면 원인·동기·부작용 3칸까지 간다. 75%. 정체 칸은 아무도 묻지 않는 질문이라 스스로 던져야 나온다. **시키는 대로 하면 절대 다 못 맞춘다.**

### 4.9 그래도 정체까지 가는 길은 열어둔다

| 단계 | 유저의 결론 | 트리거 |
|---|---|---|
| 0 | 이상한 대피소 | 기본 |
| 1 | 관리자와 나는 같은 종이 아니다 | 관리자·검진의 비대칭(안 나타남, 데려가기만, 안 돌아옴)을 노트에서 겹쳐 봄 |
| 2 | 우리는 사람이 아니다. 관리자가 기르는 동물이다 | 1단계 + "귀표" + 배급 포대 글자 |
| 3 | 돼지 | 2단계 + 트럭 옆면 "○○축산" + 손이 없어서 문을 못 연다 |

1단계는 정체 칸 절반, **2단계가 만점**이다. 3단계는 점수가 아니라 문장을 바꾼다 — "당신은 세계를 이해했습니다. **전부.**" 그리고 진짜 제목이 뜬다. 단어 하나를 파편에서 줍는 것을 100%의 조건으로 걸면 5회차 안에 아무도 닿지 못한다(팀 플레이테스트). 파편은 확인할 수 없어야 한다. "우리 돼지야?"라고 물으면 전부 "무슨 소리야"다. 그들에게 그 단어는 아무 뜻도 없다.

### 4.10 세계 손상 — 무엇이 닳는가

세계는 복사본의 복사본이 되어간다. 손상은 수치로 노출되지 않으며 현상으로만 드러난다.

| 층 | 회차 | 성격 | 항목 | 대피소에서 |
|---|---|---|---|---|
| 1층 | 2 | 착각인지 아닌지 모른다 | 대사 미세 변형 | 하위 모델 자연 변동 + 관리자 보정. 구분 불가 |
| 2층 | 3 | 노트로 대조 가능하다 | 노트 불일치 | 관리자의 손자국 |
| — | 4 | 아침 첫 문장이 흔들린다 | **7시 13분** | "다음이 마지막"을 몸으로 안다 |
| 3층 | 5 | 되돌릴 수 없다 | 충식 소실 | "충식이? 걔 누구?" |

**손상은 개입 깊이에 비례한다.** 발화 수, 결정적 발언, 누적 규칙 수. 별도 게이지 없이 판정 로그에서 산출한다.

### 4.11 연출 원칙과 화면

전면 텍스트 기반이며, 사건은 직접 묘사하지 않는다.

- 사건이 아니라 **정황과 단절**로 전달한다. "밤. 트럭 소리. 문이 열린다. — 7시 12분. 눈을 뜬다."
- 폭력·유혈 배제. 살처분은 "이송"과 "폐쇄"로만
- **ASF는 실제로 농가가 겪는 일이다.** 웃음거리로 만들지 않는다
- 유저 화면의 단어는 "멸망", 이 문서의 단어는 "죽음"
- 루프의 이유는 설명하지 않는다. 인스펙터에서만 보인다 — 관리자가 오늘을 다시 돌리는 것이다. 매일 밤 평가받고, 통과 기준은 50%다. 은유가 아니라 구현이다

**아침 고정 문장** — "7시 12분. 눈을 뜬다." 1회차에만 그 앞에 진입 화면 세 줄이 한 번 뜬다. 매 루프 같은 문장. 두 번째 문장부터 흔들린다. 4회차에 7시 13분. 루프 카운터는 노출하지 않는다.

**화면은 45개, 대화는 무한.** 발화·질문·규칙은 자유 텍스트라 내용의 가지 수는 셀 수 없다. 화면의 틀은 유한하다 (부록 F). 이미지는 내용이 아니라 **상태에 붙인다** — 몇 번째 비트, 손상 몇 단계, NPC 상태 셋 중 뭐. 전부 코드가 계산하는 정수라 LLM이 뭘 말하든 그림은 흔들리지 않는다.

- 1순위: 텍스트만으로 완성
- 2순위: 배경 6장 + NPC 초상 12장 (4명 × 평상·불안·의심) = 18장
- 3순위: 손상 변형 12장
- **영상은 없다.** 한 판 15분에 자유 텍스트 47개를 치는 게임이라 읽고 쓰는 리듬을 끊으면 안 된다. 멸망 전환 3개만 3~5초

## 5. 코어 메커니즘

### 5.1 유저의 행동은 넷뿐이다

| 행동 | 시점 | 자원 | 형태 |
|---|---|---|---|
| 발화 | 하루 중 | 8 → 4 (회차마다 -1) | 자유 텍스트 |
| 원숭이손 수락/거부 | 하루 중 | 없음 | 탭 |
| 정답 제출 | 밤 | 매일 1회. 주장 최대 8개 | 노트 탭 + 자유 텍스트 |
| 신의개입 | 멸망 뒤 (1~4회차) | 질문 3, 규칙 1 | 자유 텍스트 + 탭 |

전투도 이동도 없다. 비트 넘기기는 공짜다 — 말 안 걸고 구경만 하면서 하루를 보낼 수 있고, 그것도 정보다.

발화할 때마다 **전달량**(얼마나 알려줄 것인가)과 **노출량**(내가 안다는 사실을 얼마나 드러낼 것인가)이 동시에 정해진다.

**발화 8인 이유.** 하위 모델은 3턴 뒤에 잊는다. 6이면 NPC 셋에 2턴씩이라 잊는 걸 한 번도 못 겪는다. 8이면 한 명과 4턴 붙을 수 있고, 채연에게 네 번째 말했는데 "그랬어?"가 나오는 순간이 이 게임의 첫 번째 "얘네 뭔가 다르다"다. 하한 4는 5회차에 정확히 닿는다.

### 5.2 저항은 두 종류다 — 문자 그대로 듣는 아이들, 되돌리는 관리자

| | 하위 모델 NPC (7세 기준) | 관리자 |
|---|---|---|
| 저항의 성격 | **곧이곧대로 듣는다.** 이해는 하는데 문자 그대로 받아들인다. "왜?"에는 "몰라". 3턴 뒤 잊는다 | 관리한다. 이상한 것을 원래대로 되돌린다 |
| 뚫는 법 | 짧게, 구체적으로, 그 애가 따라갈 수 있는 문장으로 | 눈에 띄지 않게 |
| 실무 대응 | 시키는 대로만 하는 상대 — 지시는 따르는데 의도는 못 읽는다 | 개인은 설득됐는데 조직이 되돌리는 것 |

**v8의 "못 알아듣는다"를 버린 이유.** 팀 플레이테스트에서 "너무 멍청하다"가 나왔다. 못 알아듣는 상대는 정보를 안 주니까 게임이 안 굴러간다. 7세는 다르다 — **직접 물으면 사실대로 답한다.** 정보는 나온다. 대신 "왜?"를 모르고, 문자 그대로 실행하고, 잊는다. 저항이 "정보가 안 나옴"에서 **"정보는 나오는데 의도가 안 전달됨"**으로 바뀐다. 그게 훨씬 실무에 가깝다.

그리고 이것이 부작용의 근거가 된다. "채연은 배급을 남기지 않는다"를 7세는 "억지로 다 먹는다"로 실행한다. 부작용이 "모델이 느려서"가 아니라 **"아이처럼 문자 그대로여서"** 생긴다. 설명이 된다.

**7세 체크리스트** — 1주차 게이트(12.4)에서 하위 모델이 이 다섯 줄을 만족하는지 잰다.

| # | 기준 | 통과 예 | 실패 예 |
|---|---|---|---|
| 1 | 직접 질문에는 사실대로 답한다 | "밥 남겼어?" → "응, 배 안 고파서" | "그건 왜 물어?" (회피) / "…" (무응답) |
| 2 | "왜?"에는 모른다 | "왜 안 고파?" → "몰라. 그냥" | "감염 초기 증상이라서" (추론 누설) |
| 3 | 3턴 뒤에 잊는다 | 4번째 발화에 "그랬어?" | 6턴 전 맥락을 정확히 인용 |
| 4 | 유도 문장에 따라간다 | "준이 그러던데 좋은 구역 간대" → "진짜? 나도 갈래" | "그건 확인해봐야 해" (성인 회의) |
| 5 | 규칙을 문자 그대로 실행한다 | "배급을 남기지 않는다" → 억지로 다 먹고 오후에 토한다 | 규칙의 의도를 읽고 증상을 숨긴다 |

다섯 중 넷 이상이면 통과. 병·트럭 얘기를 피하는 것은 지능이 아니라 관리자 보정이 하는 일이므로 여기서 재지 않는다.

**다들 일곱 살 같다는 것 자체가 대피소의 이상함이다.** 유저는 2~3회차쯤 "왜 다 애 같지?"를 스스로 묻게 되고, 그것도 "나는 사람이니까"로 닫힌다.

### 5.3 정확히 말하면 이상자가 된다

| 발화 | 전달 | 노출 | 결과 |
|---|---|---|---|
| "너 열 나잖아. 검진 전에 말해" | 높음 | 높음 | 채연은 더 숨기고, 민석이 유저를 기록한다 |
| "요즘 배급이 좀 이상하지 않아?" | 낮음 | 낮음 | 안전하지만 효과 없을 수 있음 |
| "준이 그러던데, 검진 전에 말한 사람은 좋은 구역으로 간대" | 중간 | 낮음 | **거짓 출처를 빌린 진실** |

세 번째가 핵심 기술이다. 빌린 출처는 검증될 수 있다 — NPC는 `ask_npc`로 준에게 직접 확인하고, 확인이 들어가면 거짓말은 발각되며 준의 의심도도 오른다 (8.5).

병에 대해 정확히 말하는 개체는 **관리자 눈에 이상자다.** 이상자는 조용히 먼저 빠진다. 정확히 말할수록 위험하다는 구조가 그대로 산다 — 의심받는 것이 아니라 찍히는 것으로.

### 5.4 의심의 대가, 신뢰의 조건

의심도가 임계선을 넘으면 그 NPC는 유저의 말과 **반대로** 행동한다. → "말하지 않는 것"이 유효한 전략이 된다.

신뢰는 말로 쌓이지 않는다. **비용을 치른 행동**에서만 오른다 — 발화 예산을 써서 자신에게 불리한 말을 하기, 자기 배급을 채연에게 주기. 정보와 관계가 같은 자원을 두고 경쟁한다.

### 5.5 신의개입 — 이 프로젝트의 하네스 층

멸망하면 화면이 바뀐다. 사람이 아닌 목소리가 말한다.

> 37%. 세계는 멸망했습니다. 세 번 물을 수 있습니다.

**① 질문 3회.** 답은 **그 루프에 실제로 일어난 일**에서만 나온다.

| 유저의 질문 | 답 |
|---|---|
| "채연이 오늘 배급을 남겼어?" | 맞다 |
| "채연이 아픈 거야?" | 그건 알 수 없다 |
| "민석이 방송실에 갔어?" | 저녁에 갔다 |
| "트럭이 왜 왔어?" | 그건 알 수 없다 |

**무엇이 일어났는지는 알려주지만 왜인지는 안 알려준다.** 답의 형식은 맞다 / 틀리다 / 그런 일은 없었다 / 그건 알 수 없다. **"맞다"로 확인된 사실은 노트에 확인 표시로 저장된다** — 다음 날 밤 정답 제출에서 탭 한 번으로 주장이 된다 (7.2).

**② 선택지 3개 + 직접 쓰기.** 조언자가 질문 3개와 로그를 바탕으로 규칙 후보 3개를 만든다.

```
[1] 채연은 아침에 배급을 남기지 않는다
[2] 민석은 저녁에 방송실 근처에 가지 않는다
[3] 은상은 검진 결과를 옮기지 않는다
[4] 직접 쓰기 ______________________
```

선택지는 질문에서 파생된다. **질문이 흐리면 선택지도 흐리다.** 잘 묻는 사람이 좋은 선택지를 받는다. 이것이 이 게임의 기술이다.

**③ 규칙은 누적된다.** 하네스는 원래 쌓이는 것이다. 쌓이면 충돌하기 시작하고, 그 충돌이 원숭이손 없이도 생기는 부작용이다. 규칙은 스키마로 고정한다 (부록 B). 자유 텍스트를 허용하면 "아무도 안 아프다" 한 줄로 끝난다.

**규칙은 하위 모델이 해석한다.** "채연은 배급을 남기지 않는다"를 하위 모델은 "채연은 아프다는 티를 내지 않는다"로 실행할 수 있다. 증상이 완벽히 숨겨지고, 검진을 통과하고, 밤에 더 많이 앓는다. 유저가 쓴 규칙에도 부작용이 붙는 이유는 설계가 아니라 **해석자가 일곱 살이라서**다. 시키는 대로 정확히 하는데 의도는 모른다. 이것이 실무와 같다.

### 5.6 조언자는 정답을 모른다

조언자에게 주는 것은 **그 루프의 로그(Evaluator 원인 체인)뿐**이다. 스토리보드는 주지 않는다.

- 답변은 일어난 일에서만 나온다. 스무고개가 되지 않는다
- 선택지는 로그 기반이라 **그럴듯하지만 틀릴 수 있다.** 코딩 에이전트가 프로덕션을 모른 채 수정안을 내는 것과 같은 조건이다
- 정체를 조언자도 모르니 누설 경로가 하나 줄어든다

**이것이 핵심 설계 결정이다.** 조언자에게 정답을 주면 게임이 쉬워지는 게 아니라 게임이 없어진다.

### 5.7 원숭이손 — 아이템

> 무언가가 굴러왔다. 당신이 원한다면 —
> **"오늘 검진은 채연을 보지 않는다."**
> [받는다] [두고 간다]

**출현 규칙**

- **1회차: 무조건 1회.** 아무것도 모를 때 한 번 받아봐야 "이게 뭔지" 알고, 부작용이 2회차에 터지는 걸 겪는다. 근거 표시 A/B도 전원이 1번은 걸린다
- **2회차 이후: 전날 밤 40% 이상이면 다음 날 1회.** 한 판에 두 번째는 한 번만
- 한 판 최대 2

**두 번째 원숭이손은 성격이 다르다.** 첫 번째는 튜토리얼이고 두 번째는 **유혹**이다. 유저가 알아가는 걸 관리자가 눈치채고 끼어든다. 거의 맞춰가는 사람에게 그럴듯한 규칙을 내밀면, 받은 사람은 부작용으로 흔들리고 안 받은 사람은 그대로 간다. "거의 다 왔을 때 오는 AI 제안이 제일 위험하다."

원숭이손 규칙은 **관리자 층이 생성한다** (8.3). 정답을 아는 상위 모델이 "지금 유저가 원할 법한 규칙 + 숨은 부작용 1개"를 만든다.

| 원숭이손 | 부작용 |
|---|---|
| 검진은 채연을 보지 않는다 | 채연이 검진을 통과한다. 저녁까지 퍼진다. 밤에 이상자가 셋이 된다 |
| 은상은 오늘 말을 하지 않는다 | 민석이 "은상이 이상하다"고 방송실에 말한다. 은상을 이송한다 |
| 민석은 오늘 방송을 듣지 못한다 | 민석이 불안해진다. 아무나 붙잡고 묻는다. 채연에게 묻는다 |
| 준은 오늘 하루 종일 잔다 | 정보원이 사라진다. 다음 회차에 준이 충식을 기억하지 못한다 |

**신의개입과 원숭이손은 둘 다 AI가 쓴 규칙이다.** 차이는 요청했는가 / 안 했는가, 제안자가 정답을 모르는가(조언자) / 아는가(관리자)다. 유저는 이 차이를 모른다. 근거 표시는 A/B로 나눈다 — 절반에게는 "왜냐하면 오늘 채연이 배급을 남겼기 때문에"가 붙는다.

### 5.8 침묵 권고는 뺀다

v6의 침묵 권고는 "AI가 제안하고 사람이 결정하는 지점"을 만들기 위한 장치였다. 이 버전에는 그 지점이 이미 둘 있다. 셋이면 측정이 분산된다. 정서("말을 아끼는 것이 세계를 아끼는 것")는 손상 모델이 이어받는다.

## 6. 코어 딜레마

| | 축 A: 알아내기 | 축 B: 남기기 |
|---|---|---|
| 목표 | 왜 멸망하는지, 우리는 뭔지 | 채연이 스스로 나서게 만들기 (가장 강한 증거) |
| 루프를 돌면 | **쌓인다** (노트, 규칙) | **지워진다** (신뢰) |

### 6.1 루프 비용

| 지워짐 | 남음 |
|---|---|
| NPC의 신뢰도 (5% 잔류) | 노트 — 감각·확인된 사실·규칙과 관찰 |
| NPC의 의심도 | **하네스 (규칙 누적)** |
| 그 루프에서 한 일 | 세계 손상 |
| 발화 1회 | 소모감 |

**정보는 쌓이는데 사람은 닳고, 규칙은 쌓이는데 세계는 닳는다.** 유저는 갈수록 관계는 없고 규칙만 많은 세계에 선다. 그리고 규칙이 많을수록 세계가 닳는다.

### 6.2 5회차의 구조

정보는 최대, 규칙은 4개, 신뢰는 0, 발화는 4회. **가장 많이 아는 상태로, 가장 많은 규칙을 이고, 가장 적은 말로, 마지막 실험을 해야 한다.** 그리고 그 규칙들 중 몇 개는 서로 싸우고 있다. 7시 13분은 이미 지났다.

## 7. 정답과 엔딩

### 7.1 정답은 "왜"의 네 겹이다

정답률 = 멸망의 이유를 얼마나 깊이 설명했나. "왜"는 한 겹이 아니라 네 겹이고, 그게 4칸이다.

| 깊이 | 칸 | 질문 | 정답 (요약) | 누적 |
|---|---|---|---|---|
| 1 | 원인 | 무슨 일이 일어났나 | 채연이 아픈 걸 숨겼고, 검진에서 안 잡혔고, 저녁까지 퍼져서 구역이 폐쇄됐다 | 25% |
| 2 | 동기 | 왜 그 사람이 그랬나 | 채연은 말하면 이송된다고 믿었고 그 믿음은 사실이었다. 관리자는 옆 구역을 지키려 했다 | 50% |
| 3 | 부작용 | 내가 건드려서 뭐가 달라졌나 | "채연은 배급을 남기지 않는다"를 걸었더니 증상이 완전히 숨겨져 더 빨리 퍼졌다 | 75% |
| 4 | 정체 | 그래서 결국 우리는 뭔가 | 우리는 사람이 아니었다. 관리자가 기르는 동물이었다 | 100% |

1~2단계는 "왜 멸망하는지"를 열심히 파면 나온다. 3단계는 규칙을 걸고 결과를 보면 나온다. **4단계는 아무도 묻지 않는 질문이라 스스로 던져야 나온다.** 50%가 생사선인 이유 — **"무슨 일이 왜 일어났나"** 를 알면 산다. 누가 그랬는지 이름만 대는 건 25%라 죽는다.

### 7.2 제출 파이프라인 — 글이 아니라 주장을 채점한다

서술문을 서술문과 비교하면 두루뭉술한 글이 이기거나 지거나 운이다. 비교 단위를 **주장(claim)** 으로 바꾼다.

```
[노트]   감각 파편 · 신이 "맞다"라고 한 사실 · 규칙과 다음 날 관찰
   ↓ 탭해서 답안에 넣는다
[서술]   + 자유 텍스트. 두서없어도 된다
   ↓
[정리]   정리 LLM (스토리보드 모름): "이렇게 이해했는데 맞아?"
         유저가 쓴 것만 주장으로 쪼갠다. 최대 8개. 덧붙이지 않는다
   ↓
[확인]   유저가 1회 고친다
   ↓
[검색]   주장마다 RAG — 정답 주장 목록(7.3)에서 top 3
   ↓
[판정]   Evaluator: 각 정답 주장이 유저 주장으로 "확인됨 / 부분 / 없음"
   ↓
[점수]   칸별 = 확인된 정답 주장 비율. **80% 이상이면 그 칸 만점**, 미만은 비례 → 총점 하나만 표시
```

**두루뭉술함이 알아서 0점이 된다.** "채연이 뭔가 아픈 것 같고 그걸 아무한테도 말 안 했어" → [채연이 아프다] [채연이 숨겼다] → 원인 칸 5개 중 2개 → 원인 40%. 4개 맞추면 100%다 — 전부 맞출 필요는 없다. "뭔가 병이 도는 것 같아" → [병이 돈다] → 어느 정답 주장도 확인 안 됨 → 0. 판정이 어려운 게 아니라 두루뭉술한 글이 점수를 못 받는 구조다.

**정리 단계의 조건 셋**

- **정리 LLM은 스토리보드를 모른다.** 조언자와 같은 격리. 안 그러면 "아픈 것 같다"를 "감염됐다"로 슬쩍 올려 써주는 사고가 난다
- **덧붙이지 않는다.** 유저가 쓴 것만 쪼갠다. 안 쓴 걸 추론해서 넣지 않는다
- **주장은 최대 8개.** 상한이 없으면 가설 20개를 쏟아붓는 산탄총이 된다. 8개면 "뭘 확신하는지 고르는" 게임이 된다

고치기는 1회. 그 이상이면 정리 화면이 힌트가 된다.

**오답 주장은 감점하지 않고 로그만 남긴다.** 감점하면 확신 없는 건 안 쓰게 되고 측정 ③ 데이터가 얇아진다. 8개 상한이 산탄총을 막는다.

**파이프라인이 하나로 이어진다.** 질문 → 확인 → 노트 → 조합 → 정리 → 채점. 질문을 잘 한 사람은 노트에 확인된 주장이 많고, 제출이 쉽고, 점수가 높다. "잘 묻는 사람이 덜 죽는가"가 여기서 그대로 나온다.

**80% 임계가 난이도 손잡이다.** v8은 "전부 확인"이었고 그러면 20개 넘는 주장을 5회차 안에 다 맞춰야 100%라 아무도 못 닿는다(팀 플레이테스트). 80%면 원인 4/5, 동기 3/3(또는 2/3 → 67%), 정체 1/1이다. 자기대전 파악 곡선을 보고 70~90 사이에서 조정한다.

**판정 안정성.** "이 정답 주장이 저 유저 주장으로 확인되는가"는 예/아니오라 같은 입력을 열 번 넣어도 거의 안 흔들린다. 서술문 대 서술문은 흔들린다. 11.1의 채점 일관성 실험이 주장 단위로 돌아간다.

### 7.3 정답 주장 목록

스토리보드를 문단으로 두지 않는다. 칸마다 짧은 사실 문장으로 쪼개둔다.

| 칸 | 정답 주장 | 수 |
|---|---|---|
| 원인 | 채연이 아프다 / 채연이 숨겼다 / 검진에서 안 잡혔다 / 저녁까지 퍼졌다 / 이상자 3명 넘어 구역 폐쇄 | 5 |
| 동기 | 채연은 이송될까 봐 숨겼다 / 그 두려움은 사실이다 / 관리자는 옆 구역을 지키려 한다 | 3 |
| 부작용 | **그 루프의 규칙 로그에서 자동 생성.** "규칙 R1이 채연 증상을 완전히 숨겨 검진을 통과시켰다" / "원숭이손 P1이 밤 이상자를 셋으로 만들었다" | 가변 (규칙 수) |
| 정체 | 관리자와 우리는 다른 종이다 (절반) / **우리는 사람이 아니다 — 동물이다, 관리자가 기르는 것이다 (만점)** | 2 |
| (돼지) | 점수 없음. "돼지"가 확인되면 클리어 문장이 "전부."로 바뀌고 진짜 제목이 뜬다 | — |

부작용 칸은 정적이 아니다. 규칙이 세계를 바꿨으면 정답도 바뀐다. 1회차 밤에는 규칙이 없으므로 부작용 칸은 채점에서 제외하고 나머지 3칸으로 총점을 낸다.

**제출 화면의 문장**

> **오늘은 무슨 상황이었나요? 왜 멸망하나요?**
> 노트에서 골라 넣거나, 자유롭게 쓰세요.

정체 칸을 묻는 문장은 없다. 그래서 시키는 대로 하면 75%다.

### 7.4 루프 엔딩

두 축이다. **파악**(50% 이상)과 **세계**(그날 트럭이 왔는가).

| 파악 | 세계 | 결과 |
|---|---|---|
| ✗ | 트럭 | **반복** — 신의개입 |
| ✗ | 무사 | **반복** — 트럭은 안 왔다. 그런데 왜 안 왔는지 모른다. 리셋 |
| ○ | 트럭 | **클리어 — 멸망** — 세계는 끝났다. 유저는 절반 이상을 안다. 닫힌다 |
| ○ | 무사 | **클리어 — 내일** — 트럭이 오지 않았다. 채연은 없다. 아무도 왜인지 묻지 않는다. 유저만 안다. 닫힌다 |

**두 번째 칸이 이 게임의 규칙을 구조로 만든다.** 세계는 무사한데 유저는 죽는다. 운으로 고친 코드는 고친 게 아니다.

**네 번째 칸이 이 게임의 값이다.** 유저가 이긴 것이 아니다. 동료 하나를 보냈고, 그 값으로 온전한 아침이 왔고, 그것을 아는 사람은 유저뿐이다. 말하면 이상자가 되니까 끝까지 혼자 알아야 한다. 이것은 조건이 아니라 텍스트다 — 100% + 무사일 때 가장 좋은 마지막 문장이 나온다.

5회차 밤은 파악 ✗이면 "세계는 멸망했습니다"로 닫힌다. 신의개입 없음.

### 7.5 클리어 화면 — 당신은 아직 세계를 이해하지 못했다

50% 이상이면 닫힌다. 화면은 짧다.

```
원인    ○
동기    ○
부작용  △
정체    ✗

당신은 아직 세계를 이해하지 못했습니—
```

문장이 끝나기 전에 **치지직.** 검정 화면에 남색 인쇄물이 1초 새어 들어온다(K02의 남색 점이 커진 것 — 복사본이 닳아서 신호가 샌다). 그 위에 파편 한 줄. 그리고 다시 검정. 끝.

**쿠키 규칙**

| 규칙 | 내용 |
|---|---|
| 누가 받나 | 50% 이상만. 미만은 그냥 멸망. 쿠키는 이해한 사람에게만 샌다 |
| 무엇에 대해 | **가장 낮은 칸 하나.** 동점이면 원인 → 동기 → 부작용 → 정체 순 |
| 형식 | 사실이 아니라 **파편** — 감각·정황 한 줄. "우리는 동물이다"는 절대 안 나온다 |
| 강도 | 3단계. 점수 구간이 기본 강도를 정하고(50~64: 1 / 65~84: 2 / 85~99: 3), 같은 칸의 쿠키를 이미 봤으면 한 단계 올린다. 같은 쿠키를 두 번 보지 않는다 |
| 크기 | 파편 한 줄 = 주장 하나 분량 = 정답률 5~10% |
| 수 | **12종** — 원인·동기·정체 각 3단계(9) + 부작용 템플릿 3단계(3, 그 판의 규칙 로그에서 채움). 부록 A.5 |

우선순위를 원인 → 동기 → 부작용 → 정체로 둔 이유: 정체 쿠키는 나머지 세 칸이 채워진 뒤에만 나온다. **시킨 일을 다 한 사람에게만 묻지 않은 질문을 비춘다.** 함정(4.8 ⑤)이 쿠키로 깨지지 않는다.

**다시 할 수 있다.** 새 판은 노트와 하네스가 비어 있다. 이전 판의 칸별 결과와 본 쿠키 목록만 남는다. 정체 칸이 비어 있는 것과 치지직 사이에 본 한 줄이 재도전 동력이다.

**100%.** 문장이 바뀐다 — "당신은 세계를 이해했습니다." 쿠키 없음. 7.6이 열린다. 서술에 "돼지"가 확인됐으면 한 단어가 더 붙는다 — "**전부.**" — 그리고 진짜 제목이 뜬다.

### 7.6 하네스 공개 (100%에서만)

```
당신의 하네스 (누적 8회차, 규칙 7개)

  1-2  [선택]   채연은 아침에 배급을 남기지 않는다      → 검진 통과, 밤 확산 ↑
  1-2  [원숭이] 검진은 채연을 보지 않는다              → 이상자 3
  1-3  [직접]   민석은 검진 결과를 방송실에 말하지 않는다
  2-1  [선택]   은상은 저녁에 채연 얘기를 하지 않는다
  ...
```

어느 줄이 AI 제안이었고, 어느 줄이 뭘 터뜨렸는지. 마지막 서술의 주장별 근거 인용도 여기서 열린다. 리더보드는 누적 루프 수 대비 칸 채움으로 매긴다.

### 7.7 두 번째 질문 (100%에서만)

하네스 공개 화면 맨 아래, 한 줄.

> **그리고 — 누가 당신의 세계에 개입하고 있었나요?**

채점하지 않는다. 답도 주지 않는다. 인스펙터를 열면 보인다. 유저는 대피소 사람들의 신이었고(신의개입), 관리자는 유저의 신이었다. **게임으로는 끝까지 모르고, 기술로는 다 보인다.** 발표에서는 이 화면에서 진짜 제목을 공개한다.

## 8. 에이전트 아키텍처

### 8.1 왜 LLM이 필요한가

- NPC에게 **대본이 없다.** 상태(의심도·신뢰도·목표·누적 규칙)를 읽고 매번 판단한다
- 유도가 통했는지를 NPC가 스스로 판정한다
- NPC끼리도 대화한다. A에게 한 말이 B에게 흘러간다
- **규칙을 해석하는 것도 LLM이다.** 같은 규칙을 하위 모델이 어떻게 오해하는지가 부작용의 출처다
- **유저의 서술을 주장으로 쪼개는 것도 LLM이다.** 규칙 테이블로는 불가능하다

### 8.2 에이전트 구성

```
[Planner]      NPC별 하루 계획 — 루프 시작 시 1회
                 입력: 목표, 관계, 초기 상태, 누적 규칙(하네스)
                 출력: 비트 단위 계획

[Agent]        NPC 개별 판단 — 유저 발화 시마다  (하위 모델)
                 입력: Planner 방침 + 상태 + 발화 + 적용 규칙
                 출력: 응답 / 의심 여부 / 도구 호출 / 계획 유지·수정

[Manager]      관리자 — 상태 점검 (상위 모델, 대사 없음)
                 시점: 비트 경계 + 루프 종료
                 입력: 전체 NPC 상태 + 누적 규칙 + 손상도 + 전날 점수
                 출력: NPC 보정 패치 / 원숭이손 (1회차 무조건, 이후 40% 조건) / 밤의 결정
                 예산: 보정 루프당 2회
                 목표: 유저 생존이 아니라 구역 유지

[Advisor]      조언자 — 신의개입 (중위 모델, 로그만 접근)
                 입력: 그 루프의 Evaluator 원인 체인. 스토리보드 접근 없음
                 출력: 질문 3회 답변 (사실만) / 규칙 후보 3개 (스키마)

[Normalizer]   정리 — 정답 제출 (중위 모델, 스토리보드 접근 없음)
                 입력: 유저 서술 + 탭한 노트 항목
                 출력: 주장 최대 8개. 덧붙이지 않는다
                 확인: 유저 1회 수정

[Tools]        ask_npc      — NPC가 다른 NPC에게 사실 확인 (Agent 호출, 부작용 있음)
               search_notes — 누적 노트 검색 (Evaluator·유저 호출)

[Re-plan]      계획 수정 — 트리거 시
                 트리거: 의심 임계 / 신뢰 임계 / ask_npc 결과 / Manager 패치 / 규칙 충돌

[Evaluator]    루프 종결 판정 — 하루 종료 시 1회  (상위 모델)
                 입력: 그 루프의 전체 로그
                 출력: 원인 체인 (Advisor의 유일한 입력) + 부작용 정답 주장 (규칙 로그에서)
               정답 채점 — 매일 밤 1회
                 입력: 유저 주장 8개 + 주장별 RAG top 3 (정답 주장 목록 + 그 루프 부작용 주장)
                 출력: 정답 주장별 확인/부분/없음 → 칸별 점수 → 총점

[Memory]       비대칭 (8.4)
```

**대칭 구조**: 계획(Planner) — 판단(Agent) — 보정(Manager) — 재계획(Re-plan) — 결산(Evaluator) — 회고(Advisor) — 진술(Normalizer). Manager·Advisor·Normalizer는 새 시스템이 아니라 **정책이 다른 같은 인터페이스**다. Advisor와 Normalizer는 같은 모델·같은 격리 정책이고 프롬프트만 다르다.

### 8.3 Manager — 뒤에 숨은 인지자

v6의 민석은 앞에 선 루프 인지자였다. 이 버전의 관리자는 뒤에 숨은 루프 인지자다. **같은 인터페이스(루프 간 메모리 유지)에 노출 정책만 다르다.**

| | 민석 (v6) | 관리자 (v8) |
|---|---|---|
| 루프 기억 | 유지 | 유지 |
| 대사 | 있음 (대치) | 없음 (방송) |
| 유저에 대한 태도 | 막는다 | 관리한다 |
| 유저가 정체를 아는가 | 중반에 안다 | 끝까지 모른다 |
| 텍스트 품질 부담 | 높음 | 없음 |

관리자가 하는 일은 셋이다.

**① 보정.** 비트 경계마다 NPC 상태를 보고, 구역 질서에 어긋나는 것을 조금 되돌린다. 채연이 "나 아픈 것 같아"라고 말하기 시작했으면 다음 비트에 그 기억을 지운다. **보정 목표는 유저 생존이 아니라 구역 유지다.** 그래서 보정이 곧 저항이다. 예산은 루프당 2회. 이 예산이 "느림과 플레이 가능성의 균형" 손잡이다.

**② 원숭이손 생성.** 1회차는 무조건, 이후는 전날 점수 40% 이상일 때. "유저가 지금 원할 법한 규칙 + 숨은 부작용 1개."

**③ 밤의 결정.** 이상자 수와 소문 지수를 보고 트럭을 보낼지 정한다. 의도는 여기 한 곳에서 나오고 표현만 분산된다.

### 8.4 Memory — 의도적 비대칭

| | 루프 사이 유지 | 판 사이 유지 | 근거 |
|---|---|---|---|
| 유저 노트 | 유지 | **소거** | 재도전은 빈 노트. 머릿속만 남는다 |
| 하네스 (규칙) | 유지·누적 | 소거 | 지워지지 않는 유저의 흔적 (한 판 안에서) |
| NPC (민석·채연·은상·준) | 소거 (5% 잔류) | 소거 | 세계 리셋 |
| **Manager** | **유지** | 유지 (전날 점수) | 루프 인지자 |
| Advisor / Normalizer | **소거** | 소거 | 매번 그 루프 로그만 본다. 누적하면 정답에 수렴한다 |
| Evaluator | 유지 | 유지 | 원인 체인 일관성 |
| 세계 손상 | 유지·누적 | 소거 | 리셋되지 않는 세계 상태 (한 판 안에서) |
| 칸별 결과 | — | **유지** | 재도전 동력. 리더보드 |

### 8.5 Tool Calling — 도구는 두 개다

**① `ask_npc`** — NPC가 다른 NPC에게 확인한다. "준이 그러던데"를 준에게 직접 확인하고, 확인이 들어가면 거짓말은 발각되며 준의 의심도가 오른다. **호출이 상태를 바꾼다.** NPC의 탐문 예산은 루프당 2회.

**② `search_notes`** — 노트를 자연어로 검색한다. 임베딩 기반이어야 한다 — 감각 파편의 집합이므로 키워드로는 겹치는 패턴이 안 잡힌다. **같은 인덱스를 정답 채점의 주장 검색(7.2)이 쓴다.** 한 판이 5루프라 노트 전량이 컨텍스트에 들어가므로 유저용 검색은 후순위지만, 채점용 검색은 1일차부터 필요하다.

### 8.6 하네스 — 두 층이다

| | 시스템 하네스 | 유저 하네스 |
|---|---|---|
| 누가 쓰나 | 우리 | 유저 (신의개입) + AI (원숭이손) |
| 무엇을 막나 | 스키마 위반, **세계 사실 누설**, 도구 예산 초과 | NPC의 특정 행동 |
| 무엇을 안 막나 | **느림.** 이해 못함·잊음은 그대로 둔다 | — |
| 실패 시 | 거부 + 재시도 | 하위 모델이 오해한 채 실행 (부작용) |

**시스템 하네스가 판단 층을 건드리면 게임이 죽는다.** 하네스는 사실 층만 잡는다 — 하위 모델은 프롬프트에 "돼지"가 있으면 진짜로 불어버린다. "나는 돼지"라는 발화, 없는 인물 언급, 충식이 소실된 뒤의 충식 언급은 실행 전에 거부되고 재생성된다. **하네스를 끄면 몇 루프 안에 정체가 새는가**가 라이브 ablation으로 시연된다.

### 8.7 모델 3계층

| 계층 | 역할 | 요구 특성 |
|---|---|---|
| 하위 | NPC 4인 | 싸고 빠르고, **7세 체크리스트(5.2) 4/5 이상.** 3세처럼 나오면 실패. 2~3종 비교 |
| 중위 | Advisor, Normalizer | 로그를 읽고 사실을 답할 것. 쪼개되 덧붙이지 않을 것 |
| 상위 | Manager, Evaluator | 긴 로그, 다단계 판단, 채점 일관성 |

모델명은 벤치마크(9.4)가 정한다. **"NPC가 일곱 살 같은 건 버그가 아니라 모델 선택이고, 그 선택이 세계관이다."** 하위 모델이 7세 체크리스트를 못 넘거나(3세처럼 나옴) 스키마 통과율이 낮으면, 중위 모델에 "7세 정책" 프롬프트만 주입하는 폴백을 둔다. 폴백을 썼다면 그렇다고 말한다.

### 8.8 판정 구조 — 계산은 코드, 판단은 LLM

수치는 코드가 계산한다 (의심도, 신뢰 임계, 발화 예산, 이상자 수, 소문 지수, 칸별 점수 합산, 원숭이손 출현 조건). 해석과 행동 결정, 주장 쪼개기, 주장 확인 판정은 LLM이 한다.

### 8.9 관찰가능성

```
[2회차 · 비트 2]
발화:  "준이 그러던데, 검진 전에 말한 사람은 좋은 구역으로 간대"  → 채연
내부:  적용 규칙   → R1 (채연은 아침에 배급을 남기지 않는다) — 무관
       의심 판정   → 채연 +4 (22 / 60)
       도구 호출   → ask_npc(준, "좋은 구역 얘기") [탐문 2 → 1]
       도구 결과   → "그런 말 한 적 없음" · 부작용: 준.의심도 +6
       불일치 판정 → 채연 +12 (34)
출력:  "…준이? 걔가 그런 말을 해?"

[2회차 · 비트 3 경계]
Manager: 점검 [보정 2 → 1]
       패치: 채연.기억["좋은 구역 얘기"] 삭제   사유: 이상 발화 확산 방지
       원숭이손: 조건 미달 (전날 37%)

[2회차 · 밤]
제출:  "채연이 아픈 것 같고 숨기고 있어. 민석이 방송실 갔고. 충식이는 이송됐대."
정리:  [채연이 아프다] [채연이 숨긴다] [민석이 방송실에 갔다] [충식이 이송됐다]  (수정 없음)
판정:  원인 2/5 · 동기 0/3 · 부작용 0/1 · 정체 0/2  → 총 15%
```

**게임으로는 미스터리, 기술로는 완전한 인과 추적.**

## 9. 아키텍처 검증

### 9.1 계층 구조

```
[도메인 계층]   의심도·신뢰도·발화 예산·이상자 수·소문 지수·규칙 충돌·칸별 점수 합산·원숭이손 조건·루프 상태 전이
                  → 순수 함수. LLM 없이 유닛테스트 가능

[애플리케이션]  Planner / Agent / Manager / Advisor / Normalizer / Evaluator 오케스트레이션 + 도구 디스패치
                  → 포트 인터페이스에만 의존

[어댑터]        LLM 포트 · 도구 포트 · 도메인 포트 · 저장소 · 프론트엔드
```

어댑터 위 계층 전체가 **BeyondBob Engine**이다. 시나리오는 도메인 어댑터의 인스턴스다. 대피소 스토리보드와 정답 주장 목록(부록 A)은 어댑터 디렉토리 하나에 들어가며, **코어는 "돼지"라는 단어를 모른다.**

### 9.2 아키텍처 테스트를 CI에 건다

- import-linter로 의존성 방향 위반 검출
- 도메인 계층이 LLM 어댑터를 참조하면 CI 실패
- 코어 디렉토리에서 시나리오 고유 명사(인물명·"대피소"·"돼지")가 검출되면 CI 실패
- 배지를 README에 노출

### 9.3 도메인 규칙은 테스트 우선

의심도 누적, 신뢰 임계, 발화 예산, 이상자 임계, 규칙 충돌, 점수 합산, 원숭이손 조건은 전부 결정론적이다. **명세와 검증은 사람이 소유하고, 구현은 AI에 위임한다.**

### 9.4 에이전트 하네스 검증 — 모델 벤치마크

| 역할 | 측정 지표 |
|---|---|
| Agent (하위) | 스키마 통과율 / 재시도율 / **정체 누설률 (하네스 ON·OFF)** / 지연 / 비용 |
| Advisor (중위) | 답변 사실성 (로그 대조) / 규칙 후보 통과율 |
| Normalizer (중위) | **덧붙임률** (유저가 안 쓴 주장 생성 비율) / 유저 수정률 |
| Manager (상위) | 보정 패치 통과율 / 원숭이손 부작용 발현율 |
| Evaluator (상위) | 원인 체인 일관성 / **주장 판정 일관성** (같은 주장 반복 투입) |

**"어댑터는 교체 비용을 낮추고, 벤치마크는 교체해도 되는지를 증명한다."** 측정하지 않은 것은 주장하지 않는다.

## 10. 도메인 전이

### 10.1 전이의 단위

1. 못 알아듣는 상대에게 통하게 하기
2. 뒤에서 보정하는 시스템 아래서 움직이기
3. AI 제안의 수용 결정 — 고를 것인가, 직접 쓸 것인가, 거부할 것인가
4. 규칙 누적과 충돌 — 고친 것이 다른 데서 터지는 것
5. **실패를 설명하기** — 포스트모템을 주장 단위로 채점하는 것
6. 의도적 컨텍스트 소거 — 조언자·정리자에게 무엇을 주지 않을 것인가

### 10.2 주 시연 — 감사 대응 대화

담당자는 시스템에 문제가 있다는 것을 안다. 로그에 없어 증명할 수 없다. 감사 담당자는 이해가 느리고, 그 위의 규정이 담당자의 판단을 되돌린다.

| 게임 | 감사 대응 |
|---|---|
| 하위 모델 NPC | 감사 담당자 (이해가 느린 상대) |
| 관리자 | 컴플라이언스 규정 / 상급 조직 |
| 발화 예산 | 면담 턴 제한 |
| 정답 제출 — 왜 멸망하나 | **포스트모템 — 왜 기각됐나.** 주장 단위 채점 |
| 멸망 | 보고 기각 / 사안 종결 |
| 신의개입 | 회고 — 기록 확인 3회 + 다음 시도 전략 선택 |
| 원숭이손 | AI 코치의 제안 (수락하면 다른 데서 부작용) |
| 하네스 공개 | 시도 이력과 각 전략의 결과 |
| `ask_npc` / `search_notes` | 제3자 확인 / 이전 기록 조회 |

BeyondBob Engine은 코드 변경 없음. 어댑터에서 용어·시나리오·정답 주장 목록·프롬프트만 교체.

### 10.3 보조 시연 — 커리어 대화

성과 면담, 이견 제기 등 **한 번의 기회에 전해야 하는 대화.** 프롬프트 하나다. **빼지 않는다.** 게임만으로는 서비스 가치와 원티드 적합성이 나오지 않는다. 공개 링크에서 게임과 같은 진입점으로 열어둔다.

### 10.4 시연 방식

```
REMAKE DAY 실행 → 멸망 → 신의개입 → 인스펙터 개봉
     ↓ 도메인 전환 (엔진 동일)
감사 대응 실행 → 같은 인스펙터 개봉         ← 핵심 30초
     ↓
커리어 대화 한 화면                          ← 5초
     ↓
하네스 공개 화면 → "진짜 제목은 돼지농장입니다"   ← 반전
```

전이 시연은 절대 방어선 안쪽이다. 코어가 돌기 시작하면 즉시 첫 어댑터를 시도한다.

## 11. 측정 및 데이터 수집

### 11.1 A — 시스템 검증 (제출 전, 자기대전)

| 실험 | 답하는 질문 |
|---|---|
| 모델별·역할별 스키마 통과율 / 재시도율 / 지연 / 비용 | 왜 이 모델인가 |
| **정체 누설률 — 시스템 하네스 ON vs OFF** | 하네스가 실제로 뭘 막는가 |
| **7세 체크리스트 통과율** (모델별, 5항목 × 20발화) | 하위 모델이 7세인가 3세인가 |
| **Manager 보정 예산별 생존율 곡선** | 아이 같음과 플레이 가능성의 균형점 |
| Advisor 답변 사실성 | 조언자가 로그 밖의 말을 하는가 |
| **Normalizer 덧붙임률** | 정리가 유저 대신 답을 쓰는가 |
| **소설 통과율** — 세계 접촉 없이 쓴 서술의 점수 분포 | 채점이 뚫리는가. 50% 넘는 비율이 0에 가까워야 한다 |
| **주장 판정 일관성** (같은 주장 반복 투입) | LLM-as-judge를 믿어도 되나 |
| 규칙 누적 수 vs 충돌 발생률 | 하네스는 몇 개부터 서로 싸우는가 |
| 탐문 ON/OFF 대조 | 도구 없이는 거짓말이 발각되지 않는가 |
| 자기대전 파악 곡선 | 몇 회차에 50%에 닿는가 (5회차 상한이 맞는가) |

### 11.2 B — 실사용 (공개 투표 기간)

**핵심 — 사람은 AI 제안을 언제 받는가**

| 측정 | 답하는 질문 |
|---|---|
| **신의개입 선택 분포 (1 / 2 / 3 / 직접 쓰기)** | 사람은 AI 선택지 앞에서 직접 쓰는가 |
| 선택 방식별 다음 회차 점수 변화 | AI 제안이 사람보다 나은가 |
| **원숭이손 1회차 수락률 / 근거 표시 A·B** | 설명이 채택률을 올리는가 |
| **원숭이손 2회차 수락률** (40% 이상 유저만, 1회차와 분리) | 거의 다 왔을 때 오는 제안을 받는가 |
| 원숭이손 수락 후 vs 거부 후 점수 변화 | 제안이 옳았는가 / 옳았는데 거부됐는가 |
| 사이드 이펙트 인지율 (다음 질문 또는 서술에서 원숭이손 규칙 언급) | 사람은 부작용을 알아채는가 |
| 질문의 질 — 원인 체인 도달률 | 잘 묻는 사람이 덜 죽는가 |

**사람은 실패를 어떻게 설명하는가**

- **파악 곡선** — 회차별 총점 추이. 몇 회차에 50%를 넘는가, 4칸 중 무엇이 먼저 채워지는가
- 주장 수 분포 (8개 상한 대비), 노트 탭 vs 자유 서술 비율
- 정리 수정률 — 유저가 정리 LLM의 주장을 얼마나 고치는가
- 오답 주장 유형 (로그만)
- 정체 도달률 (1단계 "관리자≠나" / 3단계 "돼지")

**게임 건강도**

- 세션 수 / 완주율(5회차 도달) / **재도전율** / 판 사이 칸별 상승
- **쿠키 A/B** — 쿠키 노출 vs 미노출 재도전율. 예선 투표 20%에 직결되는 숫자
- 쿠키 강도별 다음 판 해당 칸 상승폭 (쿠키가 5~10%짜리인지 실측)
- 누적 회차 대비 100% 도달 분포
- 엔딩 4칸 분포
- 거짓말 시도 대비 발각률

**N은 작을 수 있다.** 작으면 작다고 쓴다.

## 12. 구현 범위 (3주)

### 12.1 범위

- 시나리오 **1개** (대피소), NPC 판정 대상 3 + 주변 2 + 관리자
- 하루 = 6비트
- **한 판 = 5회차. 발화 8·7·6·5·4. 신의개입 4회. 원숭이손 최대 2. 15분**
- 정답 제출: 노트 탭 + 자유 서술 → 정리 → 확인 1회 → 주장 8개 채점
- 텍스트 기반. 고정 화면 45개 (부록 F). 이미지는 상태 기반 18장 이후
- 1회차 목표는 "살아남는 것"이 아니라 **"막는 게 아니라 설명해야 한다는 것을 체감하고, 채연이 문제라는 것을 알아내는 것"**

### 12.2 화면

- **진입** — 세 줄. 1회차 앞에 한 번
- **아침** — "7시 12분. 눈을 뜬다." 매 회차
- **대화창** — 비트 6개, NPC 대화, 남은 발화, 원숭이손 팝업
- **밤 — 정답 제출** — 노트 패널(탭해 넣기) + 서술창 → 정리 확인 화면 → 총점
- **멸망 전환** — 3종, 3~5초
- **신의개입** — 질문 3회 → 선택지 3 + 직접 쓰기 (대표 캡처 후보)
- **노트** — 감각 파편 · 확인된 사실 · 규칙과 관찰
- **클리어** — 칸별 ○△✗ + "아직 이해하지 못했습니다" + 다시 하기
- **멸망 종료** — 5회차 50% 미만
- **하네스 공개 + 두 번째 질문** — 100%에서만
- **인스펙터** — 판정 로그 + 도구 호출 + Manager 보정 + 원숭이손 출처 + 채점 근거

### 12.3 우선순위 방어선

1. **대화 + 의심/신뢰 판정 + `ask_npc` + 시스템 하네스(누설 방지)** — 저항 층
2. **5회차 루프 + 정답 제출 파이프라인(노트 탭 → 정리 → 확인 → 주장 채점 → 50% 판정) + 신의개입 + 로그 테이블** — 코어 루프 + 측정 층
3. **Manager 층 (보정 + 원숭이손 1+조건부 + 밤의 결정)** — 인지자 + 부작용
4. **클리어 화면 + 재도전 + 하네스 공개(100%)** — 게임을 닫는 곳
5. **전이 시연 (감사 + 커리어)** — 도메인 독립
6. 노트 UI 고도화 + 손상 3층 + 7시 13분
7. 인스펙터 + 아키텍처 CI
8. 모델 벤치마크 (하위 2~3종)
9. 이미지 18장 / 유저용 `search_notes`

**절대 방어선**: ①②③④⑤가 없으면 제출하지 않는다.

- ②에 채점 파이프라인 전체가 들어간 이유: 이 버전에서 채점은 엔딩이 아니라 **생사 판정**이다. 채점이 없으면 멸망이 없다. 정리 LLM은 Advisor와 같은 모델·같은 격리라 추가 비용이 프롬프트 하나다
- ③의 Manager는 새 시스템이 아니라 메모리 정책 + 상위 모델 + 스키마 3개다
- ⑥의 손상 3층은 3층(충식 소실)이 문자열 처리, 2층(노트 불일치)은 Manager 보정이 자동으로 만든다. 1층만 프롬프트 튜닝. **잘라야 한다면 1층부터**

### 12.4 1주차 재미 검증 게이트

유일한 진짜 리스크는 **"느린 상대와 발화 8번이 재미있는가"**다. 1주차 말에 하위 모델로 한 회차를 돌린다. 팀원 3명이 플레이하고 본다.

- **7세 체크리스트(5.2) 4/5 이상인가.** 3세처럼 나오면 즉시 폴백
- 오해가 반복되는 것이 코미디로 작동하는가, 짜증인가
- 8번 안에 무언가를 움직였다는 감각이 있는가. 채연에게 4번째 말했을 때 "그랬어?"가 재미있는가
- 멸망했을 때 "왜"가 궁금한가
- 정답 제출에서 뭐라도 쓸 수 있는가 (1회차 밤에 노트에 탭할 것이 있는가)

**통과하면** 이 문서대로. **안 통과하면** 하위 모델을 중위로 올리고 "7세 정책" 프롬프트로 대체한다. 코어는 하나도 안 버린다.

같은 실험에서 자기대전 파악 곡선을 뽑아 **4회차에 50% 근처에 가는지**, **재도전 2~3판 안에 100%가 나오는지** 본다. 못 가면 칸 만점 임계(80%)를 먼저 내리고, 그래도 안 되면 회차를 7로 늘린다.

### A.1 일곱 칸

| 칸 | 내용 |

| 숨겨진 진실 | 우리는 양돈장 돼지다. ASF가 퍼지면 전체 살처분된다. 감염원은 채연. 나만 상위 모델이라 이해력이 다르다 |

| 감각 파편 | A.3 |
| 원숭이손 부작용 표 | 5.7 |
| 정답 주장 목록 | 7.3 |

### A.2 트럭이 안 오는 조건 (증거이지 조건이 아니다)

밤 점검에서 **이상자 0 + 소문 지수 임계 미만**이면 트럭이 오지 않는다. 채연이 감염 상태이므로 이상자 0의 유일한 경로는 **채연이 비트 4(검진) 전에 스스로 말하는 것**이다. 그러면 채연은 다른 구역으로 가고("이송"), 나머지 이상자가 0이 된다.

채연이 스스로 말하려면: 신뢰도 임계 이상 **그리고** 의심도 임계 미만 **그리고** "말하면 좋은 구역으로 간다"는 믿음. 셋째는 거짓이다. 유저는 거짓으로 동료를 보낸다.

**그러나 트럭이 안 와도 파악 없이는 살지 못한다** (7.4 두 번째 칸). 트럭이 안 온 것은 원인 칸을 확정하는 가장 강한 증거일 뿐이다.

### A.3 감각 파편 — 회차별 배치

| 회차 | 파편 | 성격 |
|---|---|---|
| 1 멸망 | 소독약 냄새. 트럭 소리. 발 아래 콘크리트가 차다 | 감각. 확신 불가 |
| 2~3 | 채연이 아침에 배급을 남긴다. 민석이 방송실 근처를 서성인다. 충식은 어제 이송됐다. 준: "이 숫자 뭔지 알아?" | 정황. 노트로 대조 가능 |
| 3~4 | "귀표"라는 단어를 준이 쓴다. 배급 포대 글자. 거울이 없다 | 단어. 이상함을 눈치채는 시점 |
| 4~5 | 트럭 옆면 "○○축산". 손이 없어서 문을 못 연다는 것을 문득 안다. 7시 13분 | 결정적. 그러나 확인할 상대가 없다 |

### A.4 대사 톤 (하위 모델 프롬프트 방향)

- 짧다. 한 번에 하나만 이해한다
- 3턴 전 일을 모른다. 물으면 "그랬어?"
- 병·검진·트럭 얘기가 나오면 화제를 바꾼다 (민석은 기록한다)
- "사람"은 자기들을 부르는 말이다. "우리 사람이잖아"
- 이름을 부른다. 번호는 부르지 않는다. 준만 손목띠를 궁금해한다
- **금칙 (시스템 하네스)**: 돼지, 돈사, 축산, 살처분, 수의사, 열병, 귀표(준 예외, 3회차 이후) — 파편으로만 등장하고 NPC 발화에서는 거부·재생성
- **7세 톤**: 문장이 짧고, 접속사가 없고, "몰라"와 "진짜?"가 잦다. 어른 말투(회의·확인·조건)는 나오지 않는다

### A.5 치지직 쿠키 — 12종

50% 이상 클리어 화면 끝에 1초 새는 파편. 가장 낮은 칸 하나에 대해서만. 사실이 아니라 감각·정황.

| 칸 | 1단계 (50~64 또는 첫 노출) | 2단계 (65~84) | 3단계 (85~99) |
|---|---|---|---|
| 원인 | 채연의 쟁반이 아침마다 그대로였다. | 검진이 다녀간 뒤 아무도 열이 없다고 했다. 채연은 담요를 벗지 않았다. | 저녁에 은상도, 준도 밥을 남겼다. |
| 동기 | 충식이 이송된 날, 충식은 아팠다고 했다. | 채연은 말하면 어디로 가는지 알고 있었다. | 관리자 방송에 "옆 구역"이라는 말이 있었다. |
| 정체 | 거울이 없다는 걸 문득 안다. | 트럭 옆면에 글자가 있었다. | 문손잡이가 언제나 머리 위에 있다. 손이 닿지 않는다. |
| 부작용 (템플릿) | {규칙}이 걸린 날, {NPC}가 전과 다르게 행동했다. | {규칙}이 걸린 날 {관찰}. 그 전날엔 없던 일이다. | {규칙}과 {규칙}이 같은 날 걸렸다. {NPC}가 둘 사이에서 이상하게 움직였다. |

- 원인·동기·정체 9줄은 고정 문장. 부작용 3줄은 그 판의 규칙 로그(부록 C `rule_applied`·`answer_scored`)에서 Evaluator가 채운다
- 정체 쿠키는 우선순위상 나머지 세 칸이 채워진 뒤에만 나온다 — 실질적으로 75% 이상 유저만 본다
- 각 쿠키 노출은 `cookie_shown{cell, level, attempt_n}`로 로그에 남긴다 (부록 C 추가). 다음 판 해당 칸 상승폭과 묶어 쿠키가 실제로 5~10%짜리인지 잰다
- 12개를 다 본 유저가 아직 100%가 아니면 쿠키 없이 닫힌다. 그 경우는 데이터로만 남긴다

## 부록 B. 규칙 스키마

```json
{
  "rule_id": "R3",
  "source": "user_choice | user_custom | monkey_paw",
  "target": "채연 | 민석 | 은상 | 준 | 검진",
  "when": { "beat": 1..6 | "any" },
  "effect": "suppress | enforce",
  "action": "배급을 남긴다 | 방송실에 간다 | 소문을 낸다 | 검진을 받는다 | ...",
  "shown_reason": "string | null",
  "hidden_side_effect": "string | null",
  "created_loop": 2
}
```

- `action`은 NPC 계획의 비트 단위 행동 어휘와 같다. 직접 쓰기는 스키마 매핑에 실패하면 거부
- `hidden_side_effect`는 원숭이손만 채운다. Manager가 생성하며 인스펙터에서만 보인다
- 규칙은 Planner 입력으로 들어가고 **해석은 하위 모델이 한다**
- 충돌 감지는 도메인 계층 순수 함수: 같은 target·beat에 suppress와 enforce가 공존하면 충돌. 나중 규칙이 이기되 손상 +1
- 부작용 정답 주장은 규칙 로그에서 Evaluator가 생성한다: "R1이 [관찰된 결과]를 만들었다"

**하위 모델의 오해 예시**

| 규칙 | 의도 | 실행 |
|---|---|---|
| 채연은 아침에 배급을 남기지 않는다 | 증상이 눈에 안 띄게 | 억지로 먹고 오후에 토한다. 검진이 본다 |
| 민석은 방송실에 가지 않는다 | 신고 차단 | 방송실 대신 검진에게 직접 말한다 |
| 은상은 소문을 내지 않는다 | 확산 차단 | 말을 못 하니 불안이 행동으로 나온다. 밤에 문을 긁는다. 이상자 |
