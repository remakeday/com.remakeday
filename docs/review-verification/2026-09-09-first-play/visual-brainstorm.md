# 관찰·이해 장면의 이미지 구성 — 브레인스토밍

2026-09-09. 기능 설계 방향은 사용자 동의. 아래 이미지 구성은 추가 논의안이며 제작 확정안이 아니다.

## 요청과 현재 상태

사용자는 이해에 도움이 되는 이미지가 여전히 부족하고, 평상·불안·경계로 나눈 초상은 체감 의미가 적다고 보고했다. E03 한 장 교체에 머물지 않고 이미지 역할과 추가 장면을 함께 검토한다.

“이해 장면”은 낮의 관찰 장면과 밤의 이해 정리 화면을 함께 대상으로 잡는다.

- 현재 E군12장은 인물4명×상태3개다. 상태 차이는 주로 어깨·고개 방향이어서 행동이나 새로운 근거를 설명하지 않는다.
- 낮에는 비트별 배경 또는 단서 이미지가 있고 검진만 두 장을 넘겨 본다. 인물 카드는 화면 하단에서 큰 면적을 차지한다.
- 기존 단서6장은 남은 쟁반·검진 주변 채연·빈 침상·폐쇄 장면에 집중한다. 보고·소문·관리자의 권한·플레이어 개입의 결과를 시각적으로 잇는 장면은 부족하다.
- 밤의 `NightScreen`은 I01 배경 위에 텍스트 노트와 입력창을 보여 준다. 관찰 이미지와 이전 회차를 비교하는 기능이 없다.
- 기존 제작서의 “Nothing is happening”·배경의 인물 부재 원칙은 분위기 배경용이다. 사건 장면까지 그대로 적용하면 행동을 보여 주기 어렵다. 얼굴·손 비노출과 화풍은 유지하면서 사건 장면에는 식별 가능한 인물의 행동을 허용하는 방향을 제안한다.

## 선택지

| 방향 | 구성 | 장점·대가 |
|---|---|---|
| A — 고정 초상과 사건 그림 (제안) | 인물 식별용 초상1장씩, 사건 그림, 밤의 관찰 모음 | 기존 대화 조작을 유지하면서 그림을 근거로 사용하기 쉽다. 장면 제작·정보 연결이 필요하다. |
| B — 연속 장면 중심 | 인물이 등장하는 그림을 넘기며 대화·관찰 | 행동의 연결이 강하지만 화면 동선 변경과 연속 컷 제작량이 크다. |
| C — 기존 초상 유지 + 사건 추가 | 상태별 초상과 현재 화면을 유지하며 단서 추가 | 변경은 작지만 의미가 약한 초상의 면적·제작 비용 문제가 남는다. |

## A안의 이미지 역할

### 인물 식별

- 채연·민석·은상·준은 식별하기 쉬운 기준 초상을 한 장씩 정한다. 이름·옷·담요·체격으로 같은 인물을 알아보게 한다.
- 초상은 대화 상대 선택용으로 작게 배치한다. 상태 변화만 보여 주려고 큰 그림을 교체하지 않는다.
- 인물의 불안·경계가 중요하면 “대답을 피한다”, “몸을 돌려 자리를 뜬다” 같은 관찰 가능한 행동으로 표현한다. 감정의 원인을 그림이 자동 확정하지 않는다.
- A안 채택 시 E03 단독 재제작은 우선순위에서 내려간다. 기존 파일 삭제나 엔진의 인물 상태 기능 제거를 뜻하지 않는다.

### 사건 관찰

그림마다 “여기서 관찰할 수 있는 사실 하나”와 원본 사건을 정한다. 전경·후경 인물과 소품으로 관계를 보여 준다. 새로 그린 행동을 먼저 넣고 게임의 사실을 뒤에서 맞추지 않는다.

한 장면의 권장 흐름: 공간을 보여 주는 컷 → 행위를 보여 주는 컷 또는 중요한 세부 → 관련 대화 → 출처를 가진 노트.

### 밤의 이해 정리

- 이미 본 그림의 작은 카드에 회차·장면·짧은 관찰 내용을 붙인다. 누르면 원본 그림과 대화를 다시 본다.
- 이전 제출 내용 옆에서 근거를 선택해 보완한다. 원문을 보존하고 새 관찰만 별도로 구분한다.
- 같은 장소의 이전·현재 관찰을 비교할 수 있다. 실제로 본 두 장면만 비교하며, 선택하지 않은 다른 분기의 그림은 보여 주지 않는다.
- 그림 사이에 원인 화살표를 자동으로 연결하지 않는다. “내가 본 순서”와 “내가 추측한 인과”를 구분한다.
- 새 회상용 그림을 생성할 필요는 없다. 낮에 본 원본을 재사용하고 카드·출처·비교 조작은 UI로 만든다.

## 우선 제작 후보 — 첫 묶음6장

아래는 구성 검토용 작업량이다. 해당 사건의 공개 조건과 실제 실행이 먼저 확정되어야 제작한다. 기존 파일로 역할을 충족할 수 있으면 재사용한다.

| 후보 | 그림에서 볼 내용 | 추리에 주는 역할 | 사실 조건 |
|---|---|---|---|
| 관리자와 배급 질서 | 같은 스피커 아래 방송을 듣고 배급 줄에 서는 인물들 | 방송의 주체가 생활을 통제한다는 관계 | 첫 방송 사건과 연결, 정체는 숨김 |
| 채연을 관찰하는 민석 | 남겨진 쟁반 쪽을 보는 민석과 채연, 기록 도구 | 관찰 대상과 기록 행동을 연결 | 민석이 실제로 관찰·기록했을 때 |
| 방송실로 향하는 민석 | 식별 가능한 민석, 방송실 문과 전달 위치 | 앞서 본 기록이 어디로 이어지는지 질문하게 함 | 접근만 확인됐으면 “보고 완료”로 설명하지 않음 |
| 소문을 옮기는 은상 | 한 사람 곁에서 다른 사람 곁으로 옮겨가는 같은 은상 | 정보가 이동하는 경로를 보여 줌 | 소문 내용의 진위는 그림만으로 확정하지 않음 |
| 준과 번호의 세부 | 기준 초상과 같은 준, 긴 소매·띠의 가까운 관찰 | 인물의 관심사와 정체 단서를 연결 | 해당 단서가 공개된 회차, 손·얼굴 비노출 |
| 검진 동선과 채연 | 동일 장소·채연을 유지하고 검진 전후의 인물·도구 위치 차이 | 기존의 웅크린 두 그림 사이에서 빠진 행동 연결 | 실제 검진·회피 상태에 맞춤; 정상 판정은 별도 근거 필요 |

이 묶음은 기존의 쟁반·빈 침상·검진 이미지와 함께 “인물의 행동”을 보완한다. 한 회차에 새 그림6개를 일괄 공개하는 의미가 아니다.

## 후속 후보 — 필요한 흐름에 한해4장

- 이송과 빈 자리의 연결: 이미 존재하는 빈 침상과 대조할 출발 흔적. 이송된 사람이 누구인지 모르면 신원을 새로 그려 넣지 않는다.
- 트럭 단서의 가까운 관찰: 실제 공개 시점에만 식별 가능한 표기·형태를 보여 준다. 정밀 글자와 번호는 이미지 모델에 맡기지 않고 승인된 문구를 UI로 표시한다.
- 관리 대상 구역의 경계: 폐쇄 결정과 옆 구역의 관계를 관찰 가능한 범위에서 제시한다. 보지 못한 내부 사건을 도식처럼 확정하지 않는다.
- 규칙 적용 이후의 행동: 예를 들어 같은 소문 장면에서 출처를 밝히는 행동이 실행된 경우의 대응 컷. 의미의 변화가 말에만 있다면 기존 장면과 달라진 실제 대사를 사용하고 불필요한 그림은 추가하지 않는다.

자유 규칙 조합마다 새 그림을 생성하는 방식은 사용하지 않는다. 지원하는 관찰 가능한 행동에만 컷을 대응시키고, 그림이 없는 실행 결과는 정확한 기록과 대사로 보여 준다.

## 회차와 반전의 표현

- 처음에는 반복되는 배급·검진·보고가 무엇인지 파악할 수 있게 한다.
- 이후 회차에는 같은 장소와 인물의 구도를 유지하면서 새로 공개된 세부 또는 실제 행동의 변화를 보여 준다.
- 정체 단서는 공개 조건에 맞춰 제공한다. 인물의 종이나 숨은 동기를 그림이 먼저 정답으로 알려 주지 않게 한다.
- 농장주·다른 종이라는 결말은 앞서 본 스피커·통제·번호·이송 그림을 돌아보며 이해되게 한다. 낮에 보지 못한 사건을 과거 회상으로 새로 삽입하지 않는다.

## 화풍·검수

- 남색·미색 리소그래프, 제한된 주황, 낮은 시점, 얼굴·손 비노출을 유지한다.
- 같은 인물·공간·소품은 기준 그림을 참조한다. 다른 각도의 그림도 같은 장소로 읽혀야 한다.
- 핵심 행동은 배경 질감에 묻히지 않게 면적·대비를 준다. 390px에서 관찰 대상이 보이는지 확인한다.
- 중요한 정보는 그림과 동등한 관찰 설명을 제공한다. 색 차이만으로 새 사실을 전달하지 않는다.
- 이미지 조건·캡션·노트·질문의 근거가 같은 사건을 가리키는지 검사한다. 관찰과 추론을 분리한다.

## 이미지가 도움이 되는지 측정하기

- 기술 검사: 공개된 이미지의 사건 연결 누락, 현재 규칙·서술과의 모순, 관찰 카드의 원본 이동 실패를 확인한다.
- 사용자 검사: “그림에서 무엇을 보았는가”, “어느 장면을 근거로 추론했는가”, “같은 인물인지 알아보았는가”를 기록한다. 정답을 유도하는 질문은 피한다.
- 그림 노출→다시 열람→답안 근거 선택을 구분해 기록한다. 노출·클릭만으로 이해했다고 판단하지 않는다.
- 최종 점수와 별도로 그림 때문에 잘못 확정한 사실, 인물 오인, 대사 없이 이해되지 않는 컷을 기록한다.
- A/B 비교 없이 이미지의 인과적 개선 효과를 확정하지 않는다. 첫 묶음을 게임 흐름에 연결해 검증한 뒤 후속 제작을 결정한다.
