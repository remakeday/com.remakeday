## 저장과 검수

- 원본: `output/imagegen/clue-07-manager-ration-order-v1.png`부터 `clue-12-chaeyeon-checkup-route-v1.png`까지. 게임 사본: `frontend/public/assets/clues/`의 같은 파일명.
- 6장 모두 1536×1024 PNG이며 원본·게임 사본의 SHA-256이 일치한다. 정확한 파일별 해시·참조 이미지·생성 프롬프트는 `image-manifest.json`에 기록했다.
- 생성 전에 E01/E04/E07/E10, C01/C02/C03/C04, 기존 검진 2장을 직접 열어 인물·공간·화풍을 비교했다. 생성된 6장도 전부 직접 열어 검수했다.
- 채연의 단발과 담요, 민석의 짧은 머리·칼라·벨트·주황 소매, 은상의 술 달린 숄, 준의 작은 체격·헝클어진 머리·긴 후드 소매를 유지한다. 얼굴·손·동물 해부학은 노출하지 않는다.
- 기록 장면의 민석 소매 띠는 굽힌 자세에서 E04와 다른 쪽으로 보인다. 주황 띠와 작업복이라는 식별 특징은 유지되며 좌우 위치에 이야기 사실을 부여하지 않는다.
- 소문 그림은 한 순간의 대화 자세다. 이동의 전후 순서, 전달한 말과 그 진위는 공개 서술·대사로 확인해야 한다.
- 준의 띠 표식과 민석 수첩 내용은 읽을 수 없는 인쇄 흔적이다. 모델이 그린 글자를 정확한 번호나 기록 내용의 근거로 사용하지 않는다.
