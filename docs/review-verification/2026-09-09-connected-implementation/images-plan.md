## 기준과 검수

- 기존 E01(채연), E04(민석), E07(은상), E10(준)을 직접 열어 비교했고 고정 초상으로 재사용한다. E03은 별도로 재제작하지 않는다.
- 원본은 `output/imagegen/`, 게임 사본은 `frontend/public/assets/clues/`에 저장한다. 원본 폴더의 기존 gitignore를 유지한다.
- 남색·미색 리소그래프, 제한된 주황, 낮은 시점을 유지한다. 얼굴·손·동물 해부학과 미공개 정체를 묘사하지 않는다.
- 인물의 머리·의복·체격, 스피커·배관·침상의 연속성을 기준 그림과 비교한다. 이미지 글자를 사실 근거로 사용하지 않는다.
- 각 결과를 직접 열어 행동·구도·노출 제한을 검수하고, 크기 및 SHA-256으로 원본/사본 일치를 확인한다.
- 후속 4개 후보는 첫 6장과 기존 이미지의 실제 누락을 검토한 뒤 결정한다. 규칙으로 대사만 바뀐 경우 별도 장면을 만들지 않는다.

최종 생성 프롬프트·참조·파일·조건·제약·검사 결과는 `image-manifest.json`에 기록한다.
