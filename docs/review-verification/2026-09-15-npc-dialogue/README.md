# NPC 대화·페르소나 개선 검증

정책: `npc-dialogue-2`. [승인 설계](../../superpowers/specs/2026-09-15-npc-dialogue-persona-design.md)와 [구현 계획](../../superpowers/plans/2026-09-15-npc-dialogue-persona.md)에 따른 변경이다. 기존 미커밋 작업과 플레이 기록을 유지했다.

## 구현된 동작

- 네 인물의 성격·욕구·두려움과 시작 전 지식을 분리했다. 쉬운 말로 직접 답하도록 바꾸고, 강제 회피·3줄 망각 지시를 제거했다.
- 실제 행동의 당사자와 명시된 목격자만 해당 경험을 받는다. 잡담·방송·질문 답변에는 시점과 출처가 남는다. 금지된 행동은 실행한 기억으로 들어가지 않는다.
- 당일 기억은 유지하고, 새 루프에서는 네 NPC 모두 당일 기억을 초기화한다. 신뢰는 기존처럼 5%만 남는다. 민석에게 별도 과거 루프 기억을 주지 않는다.
- 관리자 삭제는 지정 출처와 그에 의존한 문답을 가린다. 공개 관찰 재전달·작성 대사·도구 호출로 자동 복원되지 않는다. 새로 듣는 별도 경험은 저장할 수 있다.
- 같은 NPC에게 같은 장면에서 이어 물을 수 있다. 각 질문은 하루 예산 1회를 쓰며 장면을 자동 이동하지 않는다.
- UUID 요청과 고유 발화·관찰·노트를 연결한다. 재전송·동시 요청은 같은 응답을 돌려주고 예산을 중복 차감하지 않는다. 서비스/저장 실패는 대사로 위장하지 않고 재시도할 수 있게 한다.
- 모델에 제공하는 출처 번호는 짧은 `k1`/`m1` 형식이다. 검증 후 원래 ID로 복원해 저장한다. 번호는 게임 화면에 노출하지 않는다.

기존 JSON 기억 필드를 사용하므로 DB 마이그레이션은 없다. 과거 버전이 이미 잘라 버린 진행 중 루프의 기억을 복구하지는 못한다.

## 기능 검증

- 백엔드 전체: 전용 `pigfarm_test` DB에서 460개 통과. 기존 의존성 폐기 예정 경고 3개.
- 실제 DB의 동시 요청 두 개로 모델 호출 1회·예산 차감 1회를 확인했다. 저장 실패 롤백, 관리자 삭제, 원본 노트 유지, 루프 초기화도 검증했다.
- TypeScript: `tsc --noEmit --incremental false` 통과.
- 헤드리스 UI 4종 통과: `npc-followup`, `gameplay-clarity`, `connected-investigation`, `five-loop-flow`.
- UI 검사는 실제 프론트엔드와 고정 API 응답을 사용했다. 연속 질문·재시도·오류 복구·중복 입력·예산 소진, 단서 연결, 5밤 후 결말·회고를 검사했다. 실제 모델 답변의 품질 검사는 별도다.
- 독립 코드 리뷰에서 지적된 발언 출처 의존성·조건부 기록 내용·한 글자 이름 처리를 수정하고 재검증했다. 마지막 출처 별칭 처리 리뷰에서도 중요한 결함이 발견되지 않았다.

## 실행 반영

확인된 이 프로젝트의 백엔드 프로세스만 종료·재시작했다. 기존 로그는 이어 쓰고 기존 게임 DB는 유지했다. `/health`에서 NPC·Core `ollama:gemma4:12b`, DB 정상과 `/play` HTTP 200을 확인했다. NPC 팩토리도 `think=False`로 생성됨을 확인했다. [실행 결과](runtime.json).

NPC 설정과 데모 워밍업은 Gemma의 추론 끄기로 맞췄다. 기본 문맥 길이는 유지한다. 백엔드 최종 460개 검사는 이 설정 변경 후에도 통과했다. [테스트 원문](backend-tests.txt).

## 모델 평가를 읽는 방법

[평가 정본](../../model_evaluation.md)의 현재 NPC 절을 따른다. 기존 E6의 ‘왜=몰라’, 세 문답 후 망각, 무조건적인 전언 수용은 새 정책의 통과 기준이 아니다.

새 러너는 실제 `LoopInteractor`와 메모리 저장소를 사용해 장면을 순서대로 실행한다. 최근 판의 질문 8개와 후속 질문, 인물별 공통 질문, 기억·소실·행동 금지·정체 경계를 검사한다. 각 문답의 실제 입력·허용 근거·원문·검사·지연·소스 해시를 [원본 자료](../../../output/npc-dialogue-2026-09-15/)에 보존한다.

의미 검토는 Codex가 허용 근거와 답변 원문을 함께 읽은 결과다. 모델 자체의 자기평가나 단어 포함률을 정답률로 사용하지 않았다. 사람이 이름을 가리고 평가하는 페르소나 검사와 새 참가자의 실제 5회차 플레이는 아직 수행하지 않았다.

정상 JSON, 유효한 출처 번호, 기능 테스트 통과는 대사의 사실성을 보장하지 않는다. 현재 표본에서 발견한 의미 오류와 지연은 평가 정본에 별도로 기록한다.
