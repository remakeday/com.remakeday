# REMAKE DAY — 음성 대사 제작 브레인스토밍

작성: 2026-09-08 · ElevenLabs 제작용 초안 · 음원 생성·게임 적용 전

## 1. 추천 방향

**핵심 관찰 장면과 인물의 짧은 반응부터 목소리를 붙인다.** 대사를 읽어주는 것에 더해, 머뭇거림·말의 속도·숨기는 태도로 인물의 상태를 전달한다. 대화 전체를 처음부터 음성화할 필요는 없다.

등장인물 다섯 명은 팀원 이름인 채연·민석·은상·준·충식이다. 인물 이름이 실제 팀원 이름이라는 사실과 실제 목소리를 사용할지는 별개의 선택이다. 기본은 인물마다 어울리는 합성 보이스를 고르는 방식이다. 팀원의 목소리를 사용할 경우에는 본인이 참여에 동의한 녹음과 사용 범위로 별도 진행한다. 이 문서에서는 목소리 복제를 전제하지 않는다.

관리자와 조언자는 추가 역할이다. 팀원 다섯 명 모두에게 현시점의 대사를 억지로 배분하지 않는다. **충식은 이미 이송돼 현재 대화에 등장하지 않는 인물**이므로, 과거 기억 장면 또는 최종 크레딧이 적절하다.

게임 중에는 사건과 인물만 말한다. 원숭이손·규칙의 개발적 의미와 모델 구조는 **5회차 최종 답안 제출 이후**에 설명한다. 음성 유무·청취 여부·개입 사용 방식은 이해도 점수의 직접 조건이 아니다.

## 2. 인물별 목소리와 연기

이름만으로 성별·나이·음역을 정하지 않는다. 후보 음색을 들어 팀의 선호에 맞춰 캐스팅하되, 인물별 말하는 방식은 유지한다. 기획의 ‘문자 그대로 이해하는 성향’을 과장된 아동 목소리로 표현할 필요는 없다.

| 역할 | 음성 방향 | 연기 핵심 | 피할 것 |
|---|---|---|---|
| 채연 | 작고 가까운 목소리, 짧은 문장 | 배급에서는 무심한 척, 검진·이송에서는 잠깐 멈춤 | 매번 심한 기침, 흐느낌, 알아듣기 힘든 속삭임 |
| 민석 | 또렷하고 일정한 속도 | 규칙을 믿고 설명함. 신고를 악행으로 여기지 않음 | 악역 연기, 군대식 고함, 로봇 음성 |
| 은상 | 말이 약간 빠르고 끝이 흔들림 | 남 얘기를 꺼내다 본인도 불안해짐 | 희극적 과장, 모든 문장에 비명·웃음 |
| 준 | 가볍고 담백하며 호기심 있음 | 이상한 물건을 발견해 묻지만 정답은 모름 | 설명 담당자처럼 유창한 해설 |
| 충식 | 소박하고 일상적인 목소리 | 기억 속 짧은 한마디로 부재의 무게를 만듦 | 귀신 같은 잔향, 현재 곁에서 말하는 연출 |
| 관리자 | 또렷하고 절제된 시설 안내 음성 | 일상 안내와 폐쇄를 같은 차분함으로 말함 | 사악한 웃음, 협박조, 감정적 폭발 |
| 조언자 | 중립적이고 건조하지만 명료함 | 질문할 여백을 줌 | 신성한 합창, 컴퓨터라는 정체를 드러내는 효과 |

팀원들의 참여감을 더하고 싶다면 최종 크레딧에서 각자의 실제 짧은 제작 소감을 직접 녹음하는 방법도 있다. 게임 내 캐릭터 음성과 제작자의 발언은 화면에서 구분한다.

## 3. 첫 제작 묶음 — 14개

아래는 **새로 제안하는 대사**이며 현재 구현된 발화라고 간주하지 않는다. 사건 조건과 시나리오를 확정한 뒤 연결한다. 대사별로 파일을 분리하고, 한 줄을 2가지 정도의 절제된 연기로 비교한다.

| ID | 화자 | 제작할 대사 | 연기 | 재생 조건·의미 |
|---|---|---|---|---|
| CH01 | 채연 | 배 안 고파. 너 먹어. | 담담한 척, 후반은 짧게 | 이미지 ①. 채연이 실제로 배급을 남긴 장면 |
| CH02 | 채연 | 오늘도… 다 확인해? | 검진 안내 뒤 작은 망설임 | 이미지 ②. 채연이 검진을 경계하는 분기 |
| CH03 | 채연 | 말하면… 데려가잖아. | ‘데려가’ 앞에 짧은 멈춤 | 2회차 이후 이송을 두려워한다는 믿음을 드러낼 대화 조건에서. 첫 장면에 전부 공개하지 않음 |
| MI01 | 민석 | 남기면 물어봐. 어디 아프냐고. | 익숙한 규칙을 설명 | 배급과 상태 확인의 관계를 탐문할 때. 세계 규칙으로 채택할 경우에만 |
| MI02 | 민석 | 오늘 검진은 끝났어. | 확신하는 평상 음성 | 이미지 ③. 실제 검진 종료 뒤. 발견 여부는 별도 방송이 담당 |
| EU01 | 은상 | 충식이 어제 이송됐대. 아직 안 돌아왔어. | 소문을 말하다 끝에서 조심스러워짐 | 충식의 이송과 부재가 성립하는 초기 탐문·이미지 ⑤ |
| EU02 | 은상 | 준도 남겼네. 나도… 잘 안 넘어가. | 힘이 줄고 말이 느려짐 | 이미지 ④. 은상과 준의 식사 거부가 모두 실제로 발생했을 때 |
| JU01 | 준 | 이 숫자 뭔지 알아? 이름도 있는데. | 순수한 의문 | 초반 표식 관찰. 숫자는 별도 화면·관찰 문장과 연결 |
| JU02 | 준 | 저 문은 늘 저쪽에서 열어줘. | 이상하다고 강조하지 않고 사실처럼 | 3~4회차 출입문 관찰. 누가 열어주는지 시나리오와 일치시킬 것 |
| MA01 | 관리자 | 배급을 시작합니다. 식사 후에는 각자 자리에서 대기해 주십시오. | 짧고 평온한 시설 안내 | 첫 아침. 이곳의 생활 규칙 소개 |
| MA02 | 관리자 | 오후 검진을 시작합니다. 상태가 좋지 않은 분은 별도 구역으로 이송합니다. | MA01과 같은 온도 | 이미지 ② 직전. 검진과 이송의 관계를 명시 |
| MA03 | 관리자 | 검진을 마쳤습니다. 추가 이송 대상은 없습니다. | 평온한 결과 안내 | 이미지 ③의 ‘추가 대상 없음’ 분기 전용. 실제 발견·이송 시 사용 금지 |
| MA05 | 관리자 | 구역 간 이동을 중단합니다. 다른 구역으로 퍼지는 것을 막아야 합니다. | 차분하지만 문장 사이 간격은 짧게 | 이미지 ⑥. 실제 구역 간 확산 방지 조치가 내려진 경우 |
| MA06 | 관리자 | 이 구역을 폐쇄합니다. 문에서 떨어져 대기하십시오. | 감정 변화 없이 단호하게 | 실제 폐쇄 결정 뒤. 모든 밤에 공통 재생하지 않음 |

**14개를 모두 연속으로 들려주지 않는다.** 첫 아침은 MA01 → CH01을 중심으로 짧게 시작하고, 탐문을 통해 인물의 말을 추가로 듣는다. 검진 때 MA02 → CH02가 이어진다. 중요한 순서는 ‘방송이 나온 뒤 반응했다’는 관계다.

대사로 전달한 사실은 자막과 관찰 기록에도 남긴다. 단, ‘말하면 데려간다고 채연이 말했다’는 믿음의 기록이며, 곧바로 모든 이송의 실제 결과를 확정하는 증거는 아니다.

### 충식의 과거 음성 1개 — 새 회상 연출 제안

| ID | 화자 | 대사 | 사용 조건 |
|---|---|---|---|
| CS01 | 충식 | 내 자리 비워 둬. 금방 올게. | 이미지 ⑤의 빈 침상과 연결하는 과거 회상. 현재 발화가 아님을 먼저 표시 |

현재 설정에는 충식과 실시간으로 대화하는 경로가 없다. 따라서 CS01은 **기억 장면을 새로 추가하는 경우에만** 사용한다. 플레이어가 직접 들은 기억인지, 다른 인물의 회상을 재현한 것인지 서사 출처도 정해야 한다. 출처를 만들지 않으면 본편에서 빼고 최종 회고에만 사용한다.

예시 연출: `어제, 이송되기 전의 목소리가 떠오른다.` → CS01 → 현재의 빈 침상. 유령 연출 없이 짧게 끝낸다. 이 대사 역시 ‘죽었다’는 확정 증거는 아니다.

### 조언자 1개

| ID | 화자 | 대사 | 사용 조건 |
|---|---|---|---|
| AD01 | 조언자 | 오늘 있었던 일을 세 번 물을 수 있습니다. 그다음, 내일의 규칙 하나를 정하십시오. | 1회차 후 첫 신의개입 안내. 이후에는 매번 자동 반복하지 않음 |

실제 질문의 답과 추천 세 가지는 실행마다 달라질 수 있다. 최초에는 텍스트로 제공하고, 고정 녹음으로 특정 질문의 답을 대신하지 않는다.

### 최종 개발 회고 3개

5회차 최종 답안 제출 → 이해도와 사건·정체 결말 → 아래 음성 순서. 점수와 무관하게 접근 가능하다. 조언자의 음색을 후처리 없이 명료하게 재사용하는 방식을 추천한다.

| ID | 대사 | 화면 |
|---|---|---|
| EN01 | 당신은 다섯 번의 하루를 관찰하고, 그 이유를 설명했습니다. | 회차별 이해도 변화 |
| EN02 | 하루에 걸었던 규칙은, 에이전트의 행동을 제한하는 하네스였습니다. 원숭이손은 한 가지를 바꾸면서 다른 결과를 만드는 변경이었습니다. | 규칙·원숭이손의 실제 선택 기록 |
| EN03 | 지금부터, 무엇이 적용됐고 어디서 예상과 달라졌는지 살펴봅니다. | 규칙 적용·충돌·관측된 부작용 |

‘당신은 두 번 수락했습니다’처럼 변동 수치를 고정 음원에 넣지 않는다. 수치는 실제 로그로 화면에 표시하고 위 대사는 공통 안내로 사용한다. 원숭이손을 거부한 플레이어에게 사용했다고 말하지 않는다. EN02는 장치의 의미를 설명하는 문장이다.

이 문서의 대사는 총 **24개 후보**다. 14개 핵심 → 4개 분기·반응 → 1개 후반 단서 → 1개 회상 → 1개 조언자 → 3개 회고 순으로 구성한다.

## 5. ElevenLabs 제작 방법

### 모델 추천

- **인물의 짧은 연기 대사:** Eleven v3를 첫 후보로 사용한다. 표현력이 중요한 CH02·CH03·EU01 같은 문장을 먼저 비교한다.
- **관리자 방송·최종 회고:** Eleven Multilingual v2와 v3를 같은 대본으로 비교해, 한국어 발음과 문장 끝의 안정성이 좋은 쪽을 고른다.
- 실시간 전체 대화 음성화는 후속 과제다. 지금은 검수한 음원을 미리 저장해 재생하는 방식으로 진행한다.

공식 문서는 v3를 표현력 중심 모델로, Multilingual v2를 긴 발화에서 안정적인 모델로 설명한다. 한국어 음색·이름 발음은 실제 후보로 확인해야 한다. [모델·음성 안내](https://elevenlabs.io/docs/overview/capabilities/text-to-speech)

### 캐스팅용 짧은 공통 샘플

보이스 후보마다 아래 샘플을 생성해 비교한다. 이 문장은 캐스팅용이며 게임 대사로 사용하지 않는다.

```text
채연아, 민석이가 방송 들었냐고 물었어.
은상이는 준이 옆에 있고, 충식이 자리는 비어 있어.
괜찮아. 천천히 말해.
```

이름이 뭉개지거나 문장마다 음색이 크게 바뀌는 보이스는 피한다. 이름만 듣고 인물이 구분되지 않아도 괜찮지만, 화면의 이름·초상과 목소리가 항상 동일 인물을 가리켜야 한다.

### 짧은 연기 지시 예시

연기 설명은 보이스 선택·제작 메모와 분리한다. `(검진이 두려워 떨면서)` 같은 문장을 발화 입력에 그대로 넣으면 설명까지 읽을 수 있다.

v3에서는 공식적으로 안내된 오디오 태그를 시험할 수 있다. 예:

```text
[exhales] 배 안 고파. 너 먹어.
```

```text
[whispering] 말하면… 데려가잖아.
```

먼저 태그 없는 버전을 만들고, 연기가 부족할 때 한 가지씩 추가한다. 속삭임이 너무 작으면 원래 음색으로 돌아간다. 태그 지원·효과는 모델과 보이스에 따라 다르며, v3용 태그를 다른 모델에 그대로 적용하지 않는다. v3와 다른 모델의 휴지 처리 방식도 같다고 가정하지 않는다. [TTS 제작 안내](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech), [발화 제어 안내](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)

### 관리자 방송 제작

1. 음악·잡음 없이 또렷한 원본 음성을 생성한다.
2. 스피커의 좁은 음역과 약한 공간 잔향을 후처리로 적용한다. 자음이 사라질 만큼 왜곡하지 않는다.
3. 방송 시작음은 별도 파일로 붙인다. 대사 파일 자체에 매번 합쳐 넣지 않는다.
4. ‘없습니다’와 ‘있습니다’, ‘이송’과 ‘폐쇄’를 휴대폰에서도 정확히 구분할 수 있는지 확인한다.

긴 침묵·효과음·장비 소리는 별도 트랙으로 제어한다. TTS가 우연히 만든 소리를 사건 발생의 기준으로 사용하지 않는다.

## 6. 장면 적용과 자유 대화의 관계

**미리 만든 대사와 자유 대화의 답변이 서로 다르면 안 된다.**

- 고정 음성은 시나리오가 보장하는 장면 또는 조건을 만족한 대화 분기에만 연결한다.
- 화면 자막은 실제 음성 대본과 같게 한다. 별도의 LLM 문장을 표시하면서 비슷한 고정 음성을 재생하지 않는다.
- 자유 대화에서 같은 주제가 나왔다는 이유만으로 CH03 같은 고정 답을 끼워 넣지 않는다. 상태가 맞고 그 대사를 실제 답변으로 선택한 경우에만 재생한다.
- 음원 없는 자유 대화는 텍스트로 진행한다. 이후 전체 TTS를 추가할 때도 인물의 보이스 ID를 유지한다.
- 충식 소실 단계에서는 충식 이름이 포함된 대사를 현재 인물의 발화로 무조건 재생하지 않는다. 기억·노트와 현재 인식의 차이는 별도로 연출한다.
- 검진 발견/미발견, 이송/잔류, 폐쇄/미폐쇄 분기를 구분한다. ‘몇 회차인지’만으로 상황 대사를 재생하지 않는다.

### 첫 플레이의 음성 밀도

첫 아침은 두세 발화로 시작한다. 5명의 소개를 한꺼번에 듣게 하지 않는다. 관리자의 안내와 채연의 행동으로 질문을 만들고, 은상·준의 말은 탐문이나 관찰로 발견하게 한다.

같은 고정 대사는 회차마다 자동으로 반복하기보다, 첫 노출 또는 내용이 달라진 경우에 재생한다. 기록에서 재청취는 가능하게 한다. 같은 대사가 다시 등장할 때의 의미가 중요한 장면만 의도적으로 반복한다.

## 7. BGM과 재생 제어

[BGM 제작서](bgm.md)의 규칙을 따른다.

- 한 번에 주요 음성 화자는 한 명. 방송과 NPC 대사가 겹치면 방송 → 반응 순서로 재생한다.
- 대사 시작 전 BGM을 부드럽게 낮추고 종료 뒤 복원한다. 방송과 인물 모두 자막을 제공한다.
- 사용자가 다음 장면으로 넘어가면 이전 음성과 예약된 반응을 멈춘다.
- ‘소리 끄기’, ‘대사 다시 듣기’를 제공한다. 음성이 끝날 때까지 답안 입력이나 화면 진행을 불필요하게 잠그지 않는다.
- 첫 사용자 조작 뒤 재생을 시작하며, 재생 실패 시 자막만으로 진행할 수 있게 한다.
- 말끝을 잘라 긴박함을 만들기보다, 대사의 의미가 끝난 뒤 짧은 정적을 사용한다.

## 8. 파일명·검수·제작 순서

파일명 예:

```text
voice_CH01_chaeyeon_breakfast_v1.wav
voice_MA03_manager_check_clear_v1.wav
voice_MA04_manager_check_flagged_v1.wav
voice_CS01_chungsik_memory_v1.wav
voice_EN02_development_reveal_v1.wav
```

편집용 원본과 웹용 압축본을 구분한다. 실제 원본 형식을 보존하고, 음량은 인물 간 청감 차이가 지나치지 않게 맞춘다. 대본 ID, 정확한 자막, 보이스 ID, 모델, 생성 설정, 재생 조건, 최종 파일명을 함께 기록한다. API 키는 클라이언트에 넣지 않는다.

제작 순서:

1. CH02·EU01·MA02로 인물 연기와 방송의 기준을 먼저 잡는다.
2. 기본 묶음 14개를 제작하고 6장의 단서 이미지와 함께 들어본다.
3. 발견/미발견 같은 상반된 사건 분기를 확인하고 추가 대사를 제작한다.
4. 충식 회상의 출처와 시점을 확정한 경우에만 CS01을 본편에 넣는다.
5. 최종 회고 3개를 실제 기록 화면과 연결한다.

검수 기준:

- 팀원 이름과 부정 표현이 정확히 들리는가?
- 화자의 불안·확신은 느껴지지만 연기가 정보를 덮지 않는가?
- 사진만 볼 때보다 무엇을 관찰해야 하는지 명확해지는가?
- 정답을 설명해 주는 대사가 아니라, 추론에 필요한 사실·믿음·증언인가?
- 실제로 발생하지 않은 이송·확산·폐쇄를 음성이 만들어내지 않는가?
- 과거의 충식을 현재 곁에 있는 인물로 오해하지 않는가?
- 음소거 상태에서도 자막·기록으로 동일한 정보에 접근할 수 있는가?
- 개발 의미와 실제 정체 공개가 최종 답안보다 먼저 나오지 않는가?

**첫 추천 제작은 CH02·EU01·MA02의 캐스팅 샘플이며, 이어서 CH03을 만든다.** 검진 안내에 반응하고, 나중에 두려움의 이유를 말하는 두 장면을 들어보면 음성이 단서와 인물성을 얼마나 강화하는지 판단하기 쉽다.
