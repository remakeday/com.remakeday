**파일 등록과 장면 조건은 구분한다.** 확정 장면·안내·회고에 연결한 대사는 14개다. 나머지 15개도 재생 대상으로 등록했지만, 해당 화자의 실제 발화 또는 결과 방송이 녹음 대본과 일치할 때만 재생한다. 주제가 비슷한 자유 답변을 고정 녹음으로 바꾸거나, 파일을 소진하기 위해 시나리오에 없는 검진 결과·확산 조치·정체 지식을 만들지 않는다.

대사 제작 상태:

- **파일 제작·등록 완료 34개:** 위 파일 목록(MA08~12는 2026-09-16 추가). 모두 브라우저에서 MP3 메타데이터와 재생 가능한 길이를 확인했다. 발음·연기·실제 녹음 내용의 청취 검수는 별도다.
- **확정 연결 14개:** `MA01`, `MA02`, `MA06`, `MA07`, `JU04`, `CH01`, `JU05`, `MI04`, `MI05`, `EU04`, `AD01`, `EN01`, `EN02`, `EN03`.
- **발화·결과 일치 조건 15개:** `CH02`~`CH04`, `MI01`~`MI03`, `EU01`~`EU03`, `JU01`~`JU03`, `MA03`~`MA05`. 현재 장면에 없는 조건은 새로 확정하지 않았다.
- **보류 1개:** `CS01`. 충식의 과거 발언을 들려줄 서사 출처가 먼저 필요하다.

현재 게임의 작성 대사와 행동 출처는 [시나리오](../backend/apps/scenarios/scenario_a/adapter.py)를 기준으로 확인했다. MA01·MA02 방송 자막을 녹음 대본과 맞췄다. 첫 방송의 기존 배급 순서·검진 예정·이상 신고 지시는 별도 문장으로 보존하며, 방송 기록도 같은 서버 문장을 사용한다. 폐쇄 결말의 자막은 MA06과 맞췄다.

## 1. 추천 방향

**핵심 관찰 장면과 인물의 짧은 반응부터 목소리를 붙인다.** 대사를 읽어주는 것에 더해, 머뭇거림·말의 속도·숨기는 태도로 인물의 상태를 전달한다. 대화 전체를 처음부터 음성화할 필요는 없다.

등장인물 다섯 명은 팀원 이름인 채연·민석·은상·준·충식이다. 인물 이름이 실제 팀원 이름이라는 사실과 실제 목소리를 사용할지는 별개의 선택이다. 기본은 인물마다 어울리는 합성 보이스를 고르는 방식이다. 팀원의 목소리를 사용할 경우에는 본인이 참여에 동의한 녹음과 사용 범위로 별도 진행한다. 이 문서에서는 목소리 복제를 전제하지 않는다.

관리자와 조언자는 추가 역할이다. 팀원 다섯 명 모두에게 현시점의 대사를 억지로 배분하지 않는다. **충식은 이미 이송돼 현재 대화에 등장하지 않는 인물**이므로, 과거 기억 장면 또는 최종 크레딧이 적절하다.

게임 중에는 사건과 인물만 말한다. 원숭이손·규칙의 개발적 의미와 모델 구조는 **5회차 최종 답안 제출 이후**에 설명한다. 음성 유무·청취 여부·개입 사용 방식은 이해도 점수의 직접 조건이 아니다.

## 2. 인물별 목소리와 연기

이름만으로 성별·나이·음역을 정하지 않는다. 후보 음색을 들어 팀의 선호에 맞춰 캐스팅하되, 인물별 말하는 방식은 유지한다. 최근 NPC 개선에서 ‘7세’는 쉬운 말투와 생활 중심의 관심사를 뜻한다. 질문을 이해하고 자기 경험과 이유를 말할 수 있어야 하며, 무조건적인 회피·출처 혼동·과장된 아동 연기를 기본 성격으로 삼지 않는다.

| 역할 | 음성 방향 | 연기 핵심 | 피할 것 |
|---|---|---|---|
| 채연 | 작고 가까운 목소리, 짧은 문장 | 배급에서는 무심한 척, 검진·이송에서는 잠깐 멈춤 | 매번 심한 기침, 흐느낌, 알아듣기 힘든 속삭임 |
| 민석 | 또렷하고 일정한 속도 | 규칙을 믿고 설명함. 신고를 악행으로 여기지 않음 | 악역 연기, 군대식 고함, 로봇 음성 |
| 은상 | 말이 약간 빠르고 끝이 흔들림 | 남 얘기를 꺼내다 본인도 불안해짐 | 희극적 과장, 모든 문장에 비명·웃음 |
| 준 | 가볍고 담백하며 호기심 있음 | 이상한 물건을 발견해 묻지만 정답은 모름 | 설명 담당자처럼 유창한 해설 |
| 충식 | 소박하고 일상적인 목소리 | 기억 속 짧은 한마디로 부재의 무게를 만듦 | 귀신 같은 잔향, 현재 곁에서 말하는 연출 |
| 관리자 | 또렷하고 절제된 시설 안내 음성 | 일상 안내와 폐쇄를 같은 차분함으로 말함 | 사악한 웃음, 협박조, 감정적 폭발 |
| 조언자 | 중립적이고 건조하지만 명료함 | 질문할 여백을 줌 | 신성한 합창, 컴퓨터라는 정체를 드러내는 효과 |

팀원들의 참여감을 더하고 싶다면 최종 크레딧에서 각자의 실제 짧은 제작 소감을 직접 녹음하는 방법도 있다. 게임 내 캐릭터 음성과 제작자의 발언은 화면에서 구분한다.

대사로 전달한 사실은 자막과 관찰 기록에도 남긴다. 단, ‘말하면 데려간다고 채연이 말했다’는 믿음의 기록이며, 곧바로 모든 이송의 실제 결과를 확정하는 증거는 아니다.

| EU04 | 완료 | 은상 | 혼자 깨어 있으면 무서워. 조금만 같이 있어 줘. | 조용히 기대는 느낌. 울거나 비명을 지르지 않음 | 6장면. ‘준아, 자?’ → ‘아직. 왜?’ 뒤에 이어지는 마지막 문장 |

JU05는 현재 장면에 바로 대응하는 표식 질문이다. 기존 JU01의 ‘이름도 있는데’나 JU02의 문을 여는 주체처럼 추가 사실이 필요한 대사는 조건부 후보로 유지한다. MI01의 규정, EU02의 두 인물 식사 거부도 실제 사건·출처가 확정되기 전에는 재생하지 않는다.

다른 인물의 앞뒤 대사는 자막으로 유지할 수 있다. 녹음된 부분만 원래 발화 순서에 맞춰 재생하고, 대화 전체를 음성화하기 위해 나머지 문장을 한꺼번에 추가 제작하지 않는다.

5회차 최종 답안 제출 후 회고의 해당 위치에서 사용한다. 사건·정체 공개는 현재 게임의 공개 조건을 따른다. 아래 공통 안내는 점수와 무관하게 접근할 수 있지만, 세 파일을 자동으로 연속 재생하지 않는다.

|---|---|---|---|
| EN01 | 완료 | 당신은 다섯 번의 하루를 관찰하고, 그 이유를 설명했습니다. | 최종 회고 진입. ‘하루하루의 기록’ 안내 |
| EN02 | 완료 | 하루에 걸었던 규칙은, 에이전트의 행동을 제한하는 하네스였습니다. 원숭이손은 한 가지를 바꾸면서 다른 결과를 만드는 변경이었습니다. | ‘개발 데이터 — 규칙·검사·모델 동작이 궁금하다면’을 처음 펼칠 때 |
| EN03 | 완료 | 지금부터, 무엇이 적용됐고 어디서 예상과 달라졌는지 살펴봅니다. | 개발 데이터 안의 실제 규칙 적용·충돌·부작용 기록을 살펴볼 때 |

‘당신은 두 번 수락했습니다’처럼 변동 수치를 고정 음원에 넣지 않는다. 수치는 실제 로그로 화면에 표시하고 위 대사는 공통 안내로 사용한다. 원숭이손을 거부한 플레이어에게 사용했다고 말하지 않는다. EN02는 장치의 의미를 설명하는 문장이다.

이 문서의 대사는 총 **30개**다. 기존 24개에 MA07과 현재 장면용 5개를 추가했고 EU03은 같은 ID로 개정했다. **제작·등록 완료 29개 + 보류 1개**이며, 전체 BGM 1개는 이 대사 수에 포함하지 않는다. 등록된 파일도 재생 조건을 충족해야 한다.

## 5. ElevenLabs 제작 방법

### 모델 추천

- **인물의 짧은 연기 대사:** Eleven v3를 첫 후보로 사용한다. 표현력이 중요한 CH02·CH03·EU01 같은 문장을 먼저 비교한다.
- **관리자 방송·최종 회고:** Eleven Multilingual v2와 v3를 같은 대본으로 비교해, 한국어 발음과 문장 끝의 안정성이 좋은 쪽을 고른다.
- 실시간 전체 대화 음성화는 후속 과제다. 지금은 검수한 음원을 미리 저장해 재생하는 방식으로 진행한다.

공식 문서는 v3를 표현력 중심 모델로, Multilingual v2를 긴 발화에서 안정적인 모델로 설명한다. 한국어 음색·이름 발음은 실제 후보로 확인해야 한다. [모델·음성 안내](https://elevenlabs.io/docs/overview/capabilities/text-to-speech)

### 캐스팅용 짧은 공통 샘플

보이스 후보마다 아래 샘플을 생성해 비교한다. 이 문장은 캐스팅용이며 게임 대사로 사용하지 않는다.

```text
채연아, 민석이가 방송 들었냐고 물었어.
은상이는 준이 옆에 있고, 충식이 자리는 비어 있어.
괜찮아. 천천히 말해.
```

이름이 뭉개지거나 문장마다 음색이 크게 바뀌는 보이스는 피한다. 이름만 듣고 인물이 구분되지 않아도 괜찮지만, 화면의 이름·초상과 목소리가 항상 동일 인물을 가리켜야 한다.

### 짧은 연기 지시 예시

연기 설명은 보이스 선택·제작 메모와 분리한다. `(검진이 두려워 떨면서)` 같은 문장을 발화 입력에 그대로 넣으면 설명까지 읽을 수 있다.

v3에서는 공식적으로 안내된 오디오 태그를 시험할 수 있다. 예:

```text
[exhales] 배 안 고파. 너 먹어.
```

```text
[whispering] 말하면… 데려가잖아.
```

먼저 태그 없는 버전을 만들고, 연기가 부족할 때 한 가지씩 추가한다. 속삭임이 너무 작으면 원래 음색으로 돌아간다. 태그 지원·효과는 모델과 보이스에 따라 다르며, v3용 태그를 다른 모델에 그대로 적용하지 않는다. v3와 다른 모델의 휴지 처리 방식도 같다고 가정하지 않는다. [TTS 제작 안내](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech), [발화 제어 안내](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)

### 관리자 방송 제작

1. 음악·잡음 없이 또렷한 원본 음성을 생성한다.
2. 스피커의 좁은 음역과 약한 공간 잔향을 후처리로 적용한다. 자음이 사라질 만큼 왜곡하지 않는다.
3. 방송 시작음은 별도 파일로 붙인다. 대사 파일 자체에 매번 합쳐 넣지 않는다.
4. ‘없습니다’와 ‘있습니다’, ‘이송’과 ‘폐쇄’를 휴대폰에서도 정확히 구분할 수 있는지 확인한다.

긴 침묵·효과음·장비 소리는 별도 트랙으로 제어한다. TTS가 우연히 만든 소리를 사건 발생의 기준으로 사용하지 않는다.

## 6. 장면 적용과 자유 대화의 관계

**미리 만든 대사와 자유 대화의 답변이 서로 다르면 안 된다.**

- 고정 음성은 시나리오가 보장하는 장면 또는 조건을 만족한 대화 분기에만 연결한다.
- 화면 자막은 실제 음성 대본과 같게 한다. 별도의 LLM 문장을 표시하면서 비슷한 고정 음성을 재생하지 않는다.
- 자유 대화에서 같은 주제가 나왔다는 이유만으로 CH03 같은 고정 답을 끼워 넣지 않는다. 상태가 맞고 그 대사를 실제 답변으로 선택한 경우에만 재생한다.
- 음원 없는 자유 대화는 텍스트로 진행한다. 이후 전체 TTS를 추가할 때도 인물의 보이스 ID를 유지한다.
- 충식 소실 단계에서는 충식 이름이 포함된 대사를 현재 인물의 발화로 무조건 재생하지 않는다. 기억·노트와 현재 인식의 차이는 별도로 연출한다.
- 검진 발견/미발견, 이송/잔류, 폐쇄/미폐쇄 분기를 구분한다. ‘몇 회차인지’만으로 상황 대사를 재생하지 않는다.
- 관리자에게 삭제된 기억을 전제로 하는 대사는 녹음 파일이 있어도 자동 재생하지 않는다. 실제로 새로 보고 들은 사건으로 다시 알게 된 경우는 새 출처에 연결한다.
- 새 루프에서는 민석을 포함한 네 NPC의 당일 기억이 초기화된다. 이전 녹음의 반복을 NPC가 지난 루프를 회상하는 발언으로 표현하지 않는다.

### 첫 플레이의 음성 밀도

첫 아침은 두세 발화로 시작한다. 5명의 소개를 한꺼번에 듣게 하지 않는다. 관리자의 안내와 채연의 행동으로 질문을 만들고, 은상·준의 말은 탐문이나 관찰로 발견하게 한다.

같은 고정 대사는 회차마다 자동으로 반복하기보다, 첫 노출 또는 내용이 달라진 경우에 재생한다. 기록에서 재청취는 가능하게 한다. 같은 대사가 다시 등장할 때의 의미가 중요한 장면만 의도적으로 반복한다.

반복을 느끼게 하는 공통 음성으로는 MA01을 활용할 수 있다. 실제 방송·배급 순서에 맞춰 같은 안내가 다시 들리게 하고, NPC에게 ‘지난번처럼’이라는 회상 대사를 새로 붙이지 않는다.

## 7. BGM과 재생 제어

사용자가 추가한 [스테이지1.mp3](../output/voice/스테이지1.mp3)를 **게임 전체의 공통 BGM**으로 사용한다. 현재 추가 BGM 제작은 필수 항목이 아니다. 분위기와 음성 겹침 제어는 [BGM 제작서](bgm.md)를 참고한다.

**BGM 연결 완료:** 원본을 [웹 재생 파일](../frontend/public/audio/game-bgm.mp3)로 복사해 `/play`에서 사용한다. 진입 즉시 기본 음량 25%로 자동재생을 시도하고, 브라우저가 막으면 첫 클릭이나 키 입력에서 재시도한다. 반복 재생하며, 장면·루프·최종 회고·다시 시작에서 같은 재생 위치를 유지한다. 화면 오른쪽 위의 BGM 켜기·끄기 버튼은 유지하며, 끄기 선택은 이후 조작과 다음 루프에도 유지된다. 게임 페이지를 떠나면 정지한다. 재생 실패가 게임 진행을 막지 않는다.

**대사 연결 완료:** 한 개의 대사 재생기로 방송 → 인물 대사를 순서대로 재생한다. 녹음이 있는 대사 옆의 ‘다시 듣기’로 재청취하며, 오른쪽 위 ‘음성 끄기’는 BGM과 독립적으로 유지된다. 대사 중 BGM은 7%로 부드럽게 낮아지고, 종료·실패·중단 뒤 25%로 복원된다. BGM을 꺼 둔 선택과 재생 위치는 유지한다. 장면 이동과 화면 이탈은 이전 대사·대기열을 취소하며, 음원 실패가 진행을 막지 않는다. 폐쇄 방송은 다시 듣기를 눌러도 새 재생이 끝난 뒤 자동 전환하며, ‘계속’으로 건너뛸 수 있다.

EN01은 회고 데이터를 읽은 뒤, EN02는 개발 데이터를 처음 펼칠 때만 자동 재생한다. EN03은 그 안의 실험 기록 안내에서 ‘다시 듣기’로 재생한다. `/harness/[attemptId]`로 회고를 직접 열어도 같은 음성을 사용한다. 첫 신의개입에만 AD01을 자동 재생한다. 아래는 유지할 재생 원칙이다.

- BGM은 진입 시 자동재생을 시도하고, 장면이나 회차가 바뀌어도 처음부터 재시작하지 않고 이어 재생한다.
- 한 번에 주요 음성 화자는 한 명. 방송과 NPC 대사가 겹치면 방송 → 반응 순서로 재생한다.
- 대사 시작 전 BGM을 부드럽게 낮추고 종료 뒤 복원한다. 방송과 인물 모두 자막을 제공한다.
- 사용자가 다음 장면으로 넘어가면 이전 대사 음성과 예약된 반응을 멈춘다. BGM은 이어 재생하고, 대사를 중단했을 때도 BGM 음량을 복원한다.
- ‘소리 끄기’, ‘대사 다시 듣기’를 제공한다. 음성이 끝날 때까지 답안 입력이나 화면 진행을 불필요하게 잠그지 않는다.
- 브라우저가 BGM 자동재생을 막으면 첫 사용자 조작에서 재시도한다. 대사 자동재생이 차단되면 그 시도를 종료하고 자막으로 진행하며, 해당 대사의 ‘다시 듣기’로 재시도한다. 이미 종료한 대사가 뒤늦은 일반 클릭에서 시작하지 않는다.
- 말끝을 잘라 긴박함을 만들기보다, 대사의 의미가 끝난 뒤 짧은 정적을 사용한다.

## 8. 파일명·검수·제작 순서

현재 음원 폴더는 대본 ID를 그대로 쓰는 `<ID>.mp3` 형식이다. 기존 파일명을 유지하고 추가 음원도 같은 형식으로 저장한다. 예:

```text
output/voice/CH01.mp3   # 완료
output/voice/MA07.mp3   # 완료
output/voice/JU04.mp3   # 추가 예정
output/voice/MI04.mp3   # 추가 예정
output/voice/EU03.mp3   # 개정 대본으로 추가 예정
```

편집용 원본과 웹용 압축본을 구분한다. 실제 원본 형식을 보존하고, 음량은 인물 간 청감 차이가 지나치지 않게 맞춘다. 대본 ID, 정확한 자막, 보이스 ID, 모델, 생성 설정, 재생 조건, 최종 파일명을 함께 기록한다. API 키는 클라이언트에 넣지 않는다.

재생 검증:

- [음성 재생 테스트](../frontend/tests/voice-playback.cjs): 실제 음원의 방송·대사 순서, 초기 BGM 음량·조절·복원, 다시 듣기, 장면 취소와 취소된 음성의 늦은 이벤트 무시, 음소거 유지, 다른 자유 답변의 무음 처리, 실패 복구, 29개 MP3 디코딩.
- [음성 전환 테스트](../frontend/tests/voice-transitions.cjs): 폐쇄 방송의 정상 완료·음소거·재생 중 음소거·파일 오류·자동재생 차단·차단 후 재청취·건너뛰기·다시 듣기, 회고 직접 진입.
- [5회차 흐름 테스트](../frontend/tests/five-loop-flow.cjs): 첫 조언자 안내, 폐쇄 방송 완료, 회고 3종, 다시 시작 시 음성 중단, BGM 유지.
- 작성 대사·기억 조건 관련 백엔드 테스트 36개 통과. 테스트 DB는 `pigfarm_test`를 사용했다.

아래 제작 순서는 초기 제작 당시의 기록이다. 파일 준비와 재생 연결의 현재 상태는 §0·§7을 따른다.

1. **준 JU04·JU05 → 민석 MI04·MI05 → 은상 EU03·EU04**를 제작한다. 캐릭터마다 같은 음색을 유지하며, 위 표의 문장과 파일 ID를 사용한다.
2. 완료 음원의 발음·말끝·음량과 실제 자막을 확인한다. 특히 MA01·MA02는 현재 방송과 다른 문장이므로 시나리오에 채택할 정확한 대본과 관찰 기록을 맞춘다.
3. 첫 아침은 MA01과 JU04·CH01, 소등은 MA07과 EU04를 중심으로 재생을 연결한다. 원래 대화의 앞뒤 자막과 발화 순서를 유지한다.
4. MA03/MA04의 검진 결과 분기, MA05/MA06의 실제 통제·폐쇄 사건을 확인한다. 현재 검진 장면의 ‘결과가 공개되지 않음’을 ‘추가 대상 없음’으로 해석해 재생하지 않는다.
5. AD01은 첫 신의개입 안내에, EN01~EN03은 위 회고 위치에 연결한다. 소리 끄기·재청취·장면 이동 시 중단과 BGM 복원도 확인한다.
6. 조건부 후보 8개는 플레이에서 부족한 장면이 확인되면 선택해 제작한다. CS01은 출처 확정 전까지 보류한다.

검수 기준:

- 팀원 이름과 부정 표현이 정확히 들리는가?
- 화자의 불안·확신은 느껴지지만 연기가 정보를 덮지 않는가?
- 사진만 볼 때보다 무엇을 관찰해야 하는지 명확해지는가?
- 정답을 설명해 주는 대사가 아니라, 추론에 필요한 사실·믿음·증언인가?
- 실제로 발생하지 않은 이송·확산·폐쇄를 음성이 만들어내지 않는가?

## 10. 추가 녹음 필요 목록 — 밤 단서 MA13 (2026-09-17, 녹음 완료·게임 미연결)

**인물 음성은 배제하기로 이미 결정돼 있다(2026-09-17, 사용자 확인).** 원숭이손 조건부 장면 대사(채연 CH05, 준 JU06, 민석 MI06, 은상 EU05·EU06)는 녹음하지 않는다. 이 절에서 녹음이 필요한 것은 관리자 방송 MA13 하나뿐이다.

**문장은 초안 — 시나리오 디렉터 확인 전.** 확정본이 나오면 대본을 바꾼 뒤 녹음한다. 녹음·제작은 기존 음원과 같은 방식(§5 제작 방법)으로 하고, §8 검수 기준과 파일명 형식(`<ID>.mp3`, 원본 `output/voice/`, 웹용 `frontend/public/audio/voice/`)을 따른다. 등록은 `frontend/lib/voiceMap.ts`에 화자·대본 그대로.

### 10.1 선정 기준 — 지금 게임에서 음성을 갖는 대사의 종류

`voiceMap.ts`와 §3·§4·§9를 대조한 결과, 녹음된 대사는 아래 세 종류뿐이다.

| 종류 | 예 | 재생 |
|---|---|---|
| 관리자 방송(비트 방송·결과 방송·밤 단서 방송) | MA01~MA12 | 재생 |
| 조언자·회고의 고정 안내 | AD01, EN01~EN03 | 재생 |
| 인물의 **장면 고정 대사**(`scene_dialogues`) 중 대화마다 사건을 드러내는 한 줄, 그리고 소문의 알려진 출처(`known_source`) | JU04·CH01·JU05·MI04·MI05·EU04, EU03 | **재생 보류** — `HELD_PREFIXES`(테스터6 F1 발화-자막 싱크) |

녹음하지 않은 종류: 장면 서술(`narration`) 안의 인용 대사(예: 잠재 행동 "들은 것을 그대로 전한다"의 따옴표 문장), 인물의 질문 답(`question_replies`), 자유 대화, 원숭이손 팝업 문장·제안 이유. 대화의 나머지 줄도 자막으로만 둔다(§4 "녹음된 부분만 원래 발화 순서에 맞춰 재생").

이 기준으로 원숭이손 새 설계(설계 문서 `superpowers/specs/2026-09-16-coherence-chain-design.md` §3)에서 골라도, **인물 음성은 배제 결정에 따라 녹음하지 않는다.** 조건부 장면 대사 4개(①~④)의 핵심 한 줄과 ④ 5비트의 새 `known_source` 1개는 이 기준상 "해당"이었지만 녹음 대상에서 제외한다. 소원 장면의 인용 대사(채연 "밥에서 소독약 냄새가 나.", 민석 "은상이 이상한 소리를 퍼뜨려요.", 준 "침상에 같은 숫자가 있어. 자리 번호야.")는 원래도 장면 서술 안의 문장이라 해당 없음이다. 민석 `question_replies` ③ 변형도 질문 답이라 해당 없음이다. 이 절에서 녹음할 것은 **MA13 하나뿐**이다.
