# 게임 대화·안내·가독성 복원

사용자가 직전 브레인스토밍 전체 방향을 승인했다. 문구만 바꾸는 데 그치지 않고 실제 플레이 반응을 연결한다.

- 시작 안내: 5일, 하루 6장면, 낮 대화 8/7/6/5/4회(기본 총30회), 장면마다 인물당1회, 이동 무료·충전 없음, 밤에 원문 이어쓰기와 별도 질문. 첫 행동 안내와 다시 볼 수 있는 도움말. 비트→장면, 발화→오늘 남은 대화.
- 대사: 시나리오에 작성한 장면/등장인물별 대화로 교체. 모델이 기록 낭독 후보를 고르던 호출 제거. 해당 장면의 실제 행동·규칙 변경·인물 소실과 모순되지 않게 발생 조건을 확인한다. 자동 대화는 무료이며 직접 질문은 기존 NPC 모델 사용. 기록/전언 구분은 내부에 보존하고 캐릭터가 검증 시스템 용어를 말하지 않도록 한다.
- 수첩: 본 행동·들은 말을 기록하고 해석을 대신하지 않는다. 긴 기록의 로그 재낭독을 없애고 짧은 저장 알림을 사용한다. 제안 거절의 대상 명시.
- 사용자 규칙: “민석이 보고하는 것을 내가 물어보면 상세하게 설명한다.”의 인물·질문 조건·보고 주제를 보존한다. 실제 질문 때만 효력이 발생하고 다른 주제/인물/시간으로 바꾸지 않는다. 보고 이행 여부나 보고 내용을 새로 만들지 않고 실제 행동과 본인 지식으로 답한다. 미지원 조건을 포괄적 관찰 설명으로 치환하지 않는다.
- 가독성: 손상 효과는 이미지 레이어만. 대사/입력/노트/버튼은 회차에 관계없이 선명하게. 본문18px, 보조16px, 줄간격1.7 중심으로 모바일도 검사.
- 기존 기록/점수/판 흐름 보존, 실제 테스트 DB 사용 금지, 테스트는 pigfarm_test 또는 메모리와 모의API. 브라우저 GUI를 열지 않는다.
