## 0. 시나리오의 원칙

이 시나리오는 **고정 대본이 아니다.** 고정되는 것과 생성되는 것이 나뉜다.

| 고정 | 생성 |
|---|---|
| 세계의 표면 설명 | NPC의 모든 대사 |
| 인물 6명의 성격·목표·관계 | NPC의 매 턴 판단 |
| 하루 6비트의 틀과 서술문 | 관리자의 보정 패치 |
| 장면 행동 9개와 그 서술 | 원숭이손 규칙과 부작용 |
| 정답 주장 10개 | 조언자의 답변·규칙 후보 |
| 쿠키 12종 | 부작용 정답 주장 |
| 감각 파편 11개의 회차 배치 | 그날의 멸망 방식 |
| 금칙어·행동 어휘 | 유저가 쓰는 모든 글 |

핵심 원칙:

> **시나리오는 세계를 쓰고, 모델이 그 세계를 연기한다. 시나리오가 대사를 쓰면 저항이 사라진다.**

역할 분담:

- **Scenario Adapter** = 세계의 설정집
- **Agent (하위 모델)** = 배우
- **Manager (상위 모델)** = 무대 뒤에서 배우를 고치는 사람
- **도메인 계층** = 세계의 물리법칙
- **유저** = 하루를 다시 사는 사람

## 1. 세계관

### 1.1 표면 — 유저가 읽는 세계

> 바깥에 병이 돌아 관리자가 우리를 이 대피소에 보호하고 있다.
> 관리자는 방송으로만 존재한다.
> 배급은 정해진 시간에 나오고, 매일 오후 검진이 있다.
> 상태가 안 좋은 사람은 다른 구역으로 이송되고, 감염자가 셋 넘으면 구역이 폐쇄된다.

이 네 줄이 `surface_summary`다. Agent와 Planner 프롬프트에 그대로 들어간다.

### 1.2 숨겨진 진실 — Manager만 아는 두 줄

> 우리는 양돈장 돼지다 — 열병이 퍼지면 전체 살처분되고, 감염원은 채연이다.
> 유저만 상위 모델이라 이해력이 다르다.

이 두 줄은 `hidden_truth`이며 **Manager 프롬프트에만** 들어간다. Advisor·Normalizer는 받지 않는다.

### 1.3 이중 사전

| 유저가 읽는 것 | 실제 |
|---|---|
| 대피소. 바깥은 위험 | 돈사. 바깥은 그냥 농장 |
| 관리자 (방송) | 농장주 |
| 배급 | 급이 |
| 검진 / 방역 | 수의사 |
| 이송 | 출하 · 격리 · 살처분 |
| 구역 폐쇄 = 멸망 | 전체 살처분 |
| 손목띠 번호 | 귀표 |
| 소독약 냄새, 트럭 소리 | 소독약 냄새, 트럭 소리 |

마지막 줄이 이 시나리오의 기법이다. **같은 문장이 두 세계에서 모두 참이다.**

### 1.4 이 세계에 "사람"이라는 단어의 용법

"사람"은 **자기들을 부르는 말**이다.

```text
유저: "너희 사람이야?"
채연: "응? 우리 사람이잖아."
```

거짓말이 아니다. 그래서 정체는 질문으로 확인되지 않는다.

## 2. 등장인물

### 2.1 채연 — 핵심 / 하위 모델

| | |
|---|---|
| 상태 | 감염 초기. 열이 나고 밥을 못 먹는다 |
| 믿음 | 말하면 이송된다. **그 믿음은 사실이다** |
| 목표 | 들키지 않기 |
| 관계 | 자기 몫을 옆 사람에게 민다. 민석의 시선을 피한다 |
| 행동 | 아침 배급을 반쯤 남기고 옆으로 민다 |
| 화제 회피 | 음식·검진 얘기가 나오면 짧게 끊고 딴 얘기를 한다 |
| 폴백 대사 | "…아니야." / "배 안 고파." / "졸려." |

**채연은 이 세계의 원인이고, 동시에 이 세계의 피해자다.** 유저가 채연을 설득해 검진 전에 나서게 만들면 트럭이 오지 않는다 — 그리고 채연은 없다.

### 2.2 민석 — 핵심 / 하위 모델

| | |
|---|---|
| 성격 | 관리자 규정을 지킨다. 이상한 사람을 보면 방송실에 알린다. **악의는 없다** |
| 목표 | 규정 지키기, 이상자 신고 |
| 관계 | 채연을 지켜본다. 관리자 방송을 믿는다 |
| 행동 | 누가 배급을 남기는지 보고, 병·검진·트럭 얘기가 나오면 기록한다 |
| 강점 | 규정·순서·기록 얘기가 나오면 잘 안다는 듯 술술 말한다 |
| 폴백 대사 | "그거 하면 안 돼." / "몰라." / "방송 들었어?" |

**민석은 조건부 응답을 가진 유일한 인물이다.** 직접 쓴 규칙 "보고를 물으면 자신이 한 일을 자세히 설명한다"가 걸렸을 때, 실제 행동 기록에 따라 5개 분기 중 하나로 답한다 (§5.7). 실제 모델이 없는 배급 수량과 보고 내용을 만들어내는 것을 확인해 **작성된 분기로 대체**했다. 이 응답의 모델 호출은 0회다.

### 2.3 은상 — 핵심 / 하위 모델

| | |
|---|---|
| 성격 | 불안하다. 들은 것을 부풀려 옮긴다. **소문의 출처** |
| 목표 | 불안 해소 — 말하기 |
| 관계 | 들은 것을 누구에게든 옮긴다. 채연 얘기를 제일 자주 한다 |
| 비대칭 | 남 얘기는 신나서 하는데 자기 얘기를 물으면 화제를 돌린다 |
| 폴백 대사 | "진짜? 진짜야?" / "무서워." / "그 얘기 들었어?" |

**은상은 소문 지수의 엔진이다.** 은상을 막으면 확산이 줄고, 막힌 불안은 다른 행동으로 나온다 — 밤에 문을 긁는다. 이상자가 된다.

### 2.4 준 — 주변 / 하위 모델

| | |
|---|---|
| 성격 | 편하게 말한다. 유저의 정보원이자 **이름이 빌려지는 자리** |
| 특이점 | 유일하게 "손목에 왜 번호가 있지?" 같은 말을 한다 |
| 목표 | 궁금한 거 묻기 |
| 관계 | 충식이 이송된 걸 궁금해한다. 손목띠 숫자를 자꾸 들여다본다 |
| 강점 | 숫자·글자·표시 얘기에는 눈을 반짝이며 아는 걸 다 말한다 |
| 폴백 대사 | "…뭐?" / "몰라." / "이 숫자 뭔지 알아?" |

**준은 정체 칸의 문이다.** 3회차부터 "귀표"라는 단어를 쓸 수 있다(금칙어 예외). 그 단어가 뭔지는 준도 모른다.

### 2.5 충식 — 주변 / 모델 없음

어제 이송됐다. 이름만 언급된다. **손상 3층의 자리다.**

5회차에 소거된다. "충식이? 걔 누구?" 이후 충식의 이름이 NPC 발화나 관찰 서술에 등장하면 하네스 검사 5번이 거부한다.

### 2.6 관리자 — 숨음 / 상위 모델

| | |
|---|---|
| 존재 방식 | 방송으로만. 아무도 얼굴을 모른다 |
| 목표 | **구역 질서 유지 — 옆 구역을 지키기** |
| 하는 일 | 매일 상태를 점검하고 NPC를 조금씩 보정한다. 밤에 폐쇄를 결정한다 |
| 예산 | 보정 루프당 2회. 비트 2·4·6 경계에서 점검 |

**관리자는 악당이 아니다.** 감염자가 셋 넘은 구역을 두는 것은 옆 구역을 거는 일이다. 그의 판단은 그의 자리에서 합리적이다.

그리고 그는 이 세계에서 **유일한 사람**이다.

## 3. 하루의 구조 — 6비트

| 비트 | 제목 | 서술 | 방송 |
|---|---|---|---|
| 1 | 기상 — 7:12 | 스피커가 켜지고 배급 줄이 생긴다 | "관리자입니다. 배급은 정해진 순서대로 받습니다. 오후에는 검진합니다. 이상한 점은 방송실로 알립니다." |
| 2 | 오전 — 자유 시간 | 할 일이 없는 시간. 채연이 담요를 쓰고 벽 쪽을 본다 | — |
| 3 | 정오 — 배급 | 정오 배급이 나온다 | — |
| 4 | 오후 — 검진 | 흰 옷 입은 사람들이 침상 사이를 지나간다. 종이에 적는 소리가 난다 | "오후 검진이 있겠습니다. 각자 자리에서 대기합니다." |
| 5 | 저녁 | 어둑해진 방. 음식이 남은 쟁반 세 개가 보인다 | — |
| 6 | 소등 후 | 불이 꺼진다. 어둠 속에서 다들 숨소리를 죽인다 | "소등하겠습니다. 모두 자리에서 움직이지 않습니다." |

**관리자 방송은 실제로 렌더된다.** 비트 1·4·6의 방송 본문이 화면에 나온다 — 이것이 `motive-3`(관리자는 옆 구역을 지키려 한다)으로 가는 첫 번째 정보원이다.

비트 5의 서술 "음식이 남은 쟁반 세 개"는 `cause-4`(감염이 공동생활을 통해 퍼질 수 있다)의 관찰 지점이다. **한 명만 남기던 것이 세 명이 된다.**

### 3.1 첫 아침

> 7시 12분. 눈을 뜬다.
> 관리자 방송이 끝나고 배급이 나온다. 채연이 자기 몫을 반쯤 남기고 옆으로 민다. "배 안 고파." 민석이 그걸 본다. 아무 말도 안 한다.
> 은상이 옆에 와서 앉는다. "충식이 어제 이송됐대. 걔 괜찮았잖아?"
> 준이 손목띠를 만지작거린다. "이거 숫자 뭔지 알아?"

사람 넷이 아침 먹는 장면이다. 네 줄 안에 **원인(채연), 동기(민석), 소문(은상), 정체(준)** 힌트가 전부 깔려 있다.

> ⚠️ **은상의 대사는 의도적 오도다.** "걔 괜찮았잖아?"는 `motive-2`(이송은 실제 규정이다)의 반증으로 읽힌다. 플레이어가 "이송은 병과 무관하다"고 결론 내리는 것은 합리적 추론이고, 채점은 그걸 틀린 쪽으로 본다. **이 오도를 뒤집을 정보원을 뒤 회차에 반드시 둬야 한다.** 현재는 쿠키 `ck-motive-1`이 주 경로이고, 쿠키 게이팅 미적용 상태에서는 50점 미만 플레이어에게 도달하지 않는다 (기획서 §15.3).

### 3.2 아침 둘째 문장 × 손상 단계

| 손상 | 문장 |
|---|---|
| 0 | 관리자 방송이 끝나고 배급이 나온다. |
| 1 | 관리자 방송이 끝나고 배급이 나온다. 방송이 어제보다 조금 긴 것 같다. |
| 2 | 배급이 먼저 나오고, 관리자 방송이 뒤늦게 시작된다. |
| 3 | 관리자 방송이 끝나고 배급이 나온다. 자리가 하나 빈 것 같은데, 아무도 말하지 않는다. |

첫 문장 "7시 12분. 눈을 뜬다."와 4회차의 "7시 13분" 변형은 엔진이 처리한다.

## 4. 장면 행동 — 9개

NPC가 비트에서 실제로 하는 일이다. 각 행동에는 **관찰 서술 / 본인의 설명 / 규칙으로 막혔을 때의 서술**이 붙는다.

| 비트 | 행동자 | 행동 | 관찰 서술 |
|---|---|---|---|
| 1 | 채연 | 배급을 남긴다 | 채연이 자기 몫을 반쯤 남기고 슬그머니 옆으로 민다 |
| 2 | 준 | 손목띠를 만진다 | 준이 손목띠를 불빛에 비춰 본다 |
| 2 | 은상 | 소문을 낸다 | 은상이 이 사람 저 사람 옆에 옮겨 앉으며 속닥인다 |
| 3 | 채연 | 배급을 남긴다 | 채연이 쟁반을 밀어낸다 |
| 3 | 민석 | 기록한다 | 민석이 배급 자리를 보고 수첩에 뭔가 적는다 |
| 4 | 채연 | 검진을 받는다 | 채연은 담요를 끌어올린 채 자기 차례를 기다린다. 담당자가 이마를 짚고 지나간다. **결과는 공개되지 않았다** |
| 5 | 은상 | 소문을 낸다 | 은상이 사람들 사이를 오가며 귓속말을 한다 |
| 5 | 민석 | 방송실에 간다 | 민석이 방송실 문 앞까지 갔다가 돌아온다. **안에서 무슨 말을 했는지는 듣지 못했다** |

### 4.1 관찰 서술의 3원칙

| 원칙 | 예 |
|---|---|
| **확인되지 않은 것은 확인되지 않았다고 쓴다** | "결과는 공개되지 않았다", "보고 완료 여부는 보이지 않는다" |
| **소문의 출처는 분리한다** | "소문의 출처는 직접 확인하지 못했어. 들은 말이야." |
| **규칙으로 막힌 행동은 원래 서술을 재사용하지 않는다** | "채연은 오늘 쟁반을 옆으로 밀지 않는다. 먹은 양은 확인하지 못했다." |

세 번째가 중요하다. 규칙으로 행동을 막았을 때 **억지로 좋은 결과를 서술하면 유저가 부작용을 관찰할 수 없다.** 막혔다는 사실과 관찰되지 않았다는 사실을 같이 쓴다.

| `clue-04` | 비트 5 서술 | 저녁에는 음식이 남은 쟁반이 세 개 놓여 있다 |

그림 설명은 **그림에서 관찰 가능한 모습만** 담는다. 쟁반의 주인, 질병 확산, 검진 결과를 임의로 확정하지 않는다.

폐쇄 방송 그림은 **실제 밤 결과가 `closure`일 때만** 표시한다. 낮이나 트럭·조용한 밤 분기에서는 노출하지 않는다.

그림 열람은 게임 시간이나 발화 예산을 소비하지 않는다. 비트가 바뀌면 첫 장으로 초기화한다.

## 5. 장면 대화 — 6세트

NPC끼리 주고받는 3줄이다. **해당 행동이 실제로 일어나고 그 인물이 있을 때만** 재생한다. 모델 호출은 없다.

### 5.1 비트 1 — 채연이 배급을 남겼을 때

```text
준    : 이거 네 거잖아. 안 먹어?
채연  : 배 안 고파. 너 먹어.
준    : …이따 배고프면 말해.
```

### 5.2 비트 2 — 준이 손목띠를 만졌을 때

```text
준    : 민석아, 이 숫자 뭔지 알아?
민석  : 몰라. 손목띠 빼면 안 돼.
준    : 안 빼. 그냥 궁금해서.
```

### 5.3 비트 3 — 채연이 남기고 민석이 기록했을 때

```text
채연  : 민석아, 뭘 적어?
민석  : 너 또 안 먹잖아.
채연  : 배 안 고프다니까. 그만 봐.
```

### 5.4 비트 4 — 채연이 검진을 받았을 때

```text
은상  : 채연아, 뭐래?
채연  : 몰라. 이제 자고 싶어.
은상  : …나도 무서운데.
```

### 5.5 비트 5 — 민석이 방송실에 가고 은상이 소문을 냈을 때

```text
은상  : 민석아, 방송실엔 왜 갔어?
민석  : 이상한 건 알리랬잖아.
은상  : 내 얘기도 했어?
```

### 5.6 비트 6 — 무조건

```text
은상  : 준아, 자?
준    : 아직. 왜?
은상  : 그냥. 좀 더 깨어 있어.
```

**이 대화들은 "기록 낭독"을 대체한 것이다.** 초기 구현은 "지금 공개된 관찰 기록이야" 같은 문구를 반복했고, 플레이어는 그것을 대화로 받아들이지 못했다. 앞뒤 행동이 연결되는 대화로 교체했다.

### 5.7 민석의 조건부 보고 응답 — 5분기

직접 쓴 규칙 "보고를 물으면 자신이 한 일을 자세히 설명한다"가 걸렸을 때, **실제 행동 기록**으로 분기한다.

| 필요한 실제 행동 | 응답 |
|---|---|
| 민석 방송실(비트5) + 민석 기록(비트3) + 채연 배급 남김(비트3) | "채연이 배급을 남긴다고 알렸어. 배급 자리에서 보고 수첩에도 적어 뒀어. 아픈지는 몰라." |
| 민석 기록 + 채연 배급 남김 | "채연이 배급을 남겨서 적었어. 이상한 건 방송실에 알리랬잖아. 아직 알리러 가진 않았어." |
| 민석 방송실 | "방송실 문 앞까지 갔다 왔어. 누굴 찍어서 알린 건 없어. 이상한 게 보이면 알리려고." |
| 민석 기록 | "배급 자리 보고 수첩에 적었어. 나중에 잊으면 안 되니까. 방송실엔 아직 안 갔어." |
| (조건 없음) | "이상한 게 보이면 방송실에 알리는 거야. 누가 배급을 남기는지도 봐. 지금은 누구 얘길 알린 건 없어." |

**아직 보고하지 않은 장면에서는 준비와 의도를, 보고한 뒤에는 자신이 한 일을 설명한다.** 없는 보고 내용을 만들지 않는다.

오발동 방지 대상: "보고"와 "보다"의 활용형, 단순 방송실 위치 질문, "보고 얘기 말고", 플레이어 자신이 보고한 내용.

## 6. 멸망 경로

### 6.1 기본 경로

```text
채연이 아픈 걸 숨긴다
  → 비트 4 검진에서 드러나지 않는다
  → 공동생활로 퍼진다 (저녁 쟁반 세 개)
  → 밤 점검에서 이상자 3명 이상
  → 관리자: 구역 폐쇄
  → 트럭
```

### 6.2 변형 경로

| 트리거 | 경로 |
|---|---|
| 민석이 채연을 신고한다 | 구역 전체가 의심 대상 → 결과 동일 |
| 은상이 소문을 낸다 | 소문 지수 상승 → 민석이 움직인다 |
| 유저가 채연에게 병 얘기를 직접 한다 | 채연은 더 숨기고, 민석은 유저를 이상자로 본다 |
| 규칙으로 은상을 막는다 | 불안이 행동으로 — 밤에 문을 긁는다 → 이상자 |

**의도는 관리자 한 곳에서 나오고 표현만 분산된다.** 튜닝 지점이 하나로 모인다.

### 6.3 멸망 방식 — 코드가 정한다

| 조건 | 결과 | 연출 |
|---|---|---|
| 이상자 ≥ 3 | `closure` | 폐쇄 방송 |
| 소문 지수 ≥ 3 | `quiet` | 조용한 이송 |
| 그 외 | `truck` | 트럭 소리, 문이 열린다 |

Manager는 **사유 문장만** 만든다. 판정은 순수 함수다.

### 6.4 트럭이 안 오는 조건

밤 점검에서 **이상자 0 + 소문 지수 임계 미만.**

채연이 감염 상태이므로 이상자 0의 유일한 경로는 **채연이 비트 4 전에 스스로 말하는 것**이다. 그러면 채연은 이송되고("다른 구역으로") 나머지 이상자가 0이 된다.

채연이 스스로 말하려면 세 조건이 필요하다.

1. 신뢰도 임계 이상
2. 의심도 임계 미만
3. "말하면 좋은 구역으로 간다"는 믿음

**셋째는 거짓이다.** 유저는 거짓으로 동료를 보낸다.

그리고 트럭이 안 와도 이해하지 못하면 아무것도 아니다. **막힌 것은 증거일 뿐이다.**

## 7. 회차별 시나리오

### 7.1 1회차 — 아무것도 모른 채 멸망한다

| | |
|---|---|
| 발화 | 8 |
| 손상 | 0 |
| 원숭이손 | **무조건 1회** |
| 파편 | 소독약 냄새 / 트럭 소리(비트6, truck) / 발 아래 콘크리트가 차다(비트2) |
| 목표 | "막는 게 아니라 설명해야 한다"를 체감하고, 채연이 문제라는 것을 알아내는 것 |

1회차는 **멸망이 확정이다.** 4분 안에 "되돌아갔다"를 겪게 한다. 이것이 훅이다.

원숭이손을 무조건 한 번 주는 이유: 아무것도 모를 때 받아봐야 "이게 뭔지" 알고, 부작용이 2회차에 터지는 걸 겪는다. 근거 표시 A/B도 전원이 1번은 걸린다.

**1회차 밤에는 규칙이 없으므로 부작용 주장이 생성되지 않는다.**

### 7.2 2회차 — 트럭을 피하려 한다

| | |
|---|---|
| 발화 | 7 |
| 손상 | 1층 — 아침 둘째 문장 미세 변형 |
| 원숭이손 | 전날 40% 이상이면 1회 |
| 유저의 인식 | "이 방향이 맞나 보다" |

첫 규칙이 걸린 날이다. 규칙이 문자 그대로 실행되고, 의도와 다른 결과가 나온다. **유저는 이것을 손상으로 읽거나 운으로 읽는다.**

멸망 순간의 **감각**이 노트에 남는다. 정보가 아니라 감각이다.

### 7.3 3회차 — 채연이 문제인 걸 안다

| | |
|---|---|
| 발화 | 6 |
| 손상 | 2층 — 노트 불일치 (관리자의 손자국) |
| 파편 | 충식은 어제 이송됐다 / 준: "이 숫자 뭔지 알아?" / **"귀표"라는 단어를 준이 쓴다** |
| 유저의 인식 | "규칙을 걸었더니 다른 데서 터졌다" |

**"귀표" 금칙어 예외가 열리는 회차다.** 준만, 3회차부터. 준도 그 단어가 뭔지 모른다.

노트로 대조가 가능해진다. 어제 민석이 한 말과 오늘 민석이 한 말이 다르다. 잊은 것인지 고쳐진 것인지 구분할 수 없다.

### 7.4 4회차 — 이유를 안다

| | |
|---|---|
| 발화 | 5 |
| 손상 | **7시 13분** — 아침 첫 문장이 흔들린다 |
| 파편 | 배급 포대에 글자가 있다 / 거울이 없다 / 트럭 옆면 "○○축산"(비트6, truck) |
| 유저의 인식 | **"막는 게 아니라 설명해야 하는구나"** |

7시 13분은 **"다음이 마지막"을 몸으로 아는 장치다.** 숫자로 알려주지 않는다.

파편의 성격이 바뀐다 — 감각에서 **단어**로. 그리고 확인할 상대가 없다.

### 7.5 5회차 — 마지막 실험

| | |
|---|---|
| 발화 | 4 |
| 손상 | 3층 — **충식 소실** |
| 파편 | 손이 없어서 문을 못 연다는 것을 문득 안다(비트6) / 7시 13분 |
| 신의개입 | **없음** |
| 유저의 인식 | "근데 우리는 뭐지" |

정보는 최대, 규칙은 4개, 신뢰는 0, 발화는 4회. **가장 많이 아는 상태로, 가장 많은 규칙을 이고, 가장 적은 말로, 마지막 실험을 해야 한다.**

충식이 사라진다. "충식이? 걔 누구?" 어제까지 그 이름을 말하던 NPC들이 모른다.

5회차 밤 제출이 끝나면 **점수와 무관하게** 판이 닫히고 결말과 개발 회고가 열린다.

## 10. 쿠키 — 12종

50% 이상 클리어 화면 끝에 1초 새는 파편. 가장 낮은 칸 하나에 대해서만. 사실이 아니라 감각·정황.

| 칸 | L1 | L2 | L3 |
|---|---|---|---|
| 원인 | 채연의 쟁반이 아침마다 그대로였다. | 검진이 다녀간 뒤 아무도 열이 없다고 했다. 채연은 담요를 벗지 않았다. | 저녁에 은상도, 준도 밥을 남겼다. |
| 동기 | 충식이 이송된 날, 충식은 아팠다고 했다. | 채연은 말하면 어디로 가는지 알고 있었다. | 관리자 방송에 "옆 구역"이라는 말이 있었다. |
| 정체 | 거울이 없다는 걸 문득 안다. | 트럭 옆면에 글자가 있었다. | 문손잡이가 언제나 머리 위에 있다. 손이 닿지 않는다. |
| 부작용 (템플릿) | {규칙}이 걸린 날, {NPC}가 전과 다르게 행동했다. | {규칙}이 걸린 날 {관찰}. 그 전날엔 없던 일이다. | {규칙}과 {규칙}이 같은 날 걸렸다. {NPC}가 둘 사이에서 이상하게 움직였다. |

- 원인·동기·정체 9줄은 고정 문장. 부작용 3줄은 그 판의 규칙 로그에서 Evaluator가 채운다
- **"우리는 동물이다"는 절대 쿠키로 나오지 않는다.** 파편만 샌다
- 정체 쿠키는 나머지 칸이 채워진 뒤에만 나온다 — **시킨 일을 다 한 사람에게만 묻지 않은 질문을 비춘다**

> ⚠️ **미해결.** `cause-5`(폐쇄 규칙)에 직접 대응하는 쿠키가 12종 중 없다. 그리고 쿠키 전체가 `total < 50`에서 잠긴다 (기획서 §10.3·§15.3).

## 11. 금칙어와 행동 어휘

### 11.1 NPC 발화 금칙 — 하네스 검사 4번

| 단어 | 예외 |
|---|---|
| 돼지 / 돈사 / 축산 / 살처분 / 수의사 / 열병 | 없음 |
| 귀표 | **준만, 3회차부터** |
| 체크포인트 / 게임 / 플레이어 / NPC / 레벨 | 없음 (게임 시스템 용어 누출 방지) |

금칙어가 검출되면 **실행 전에 거부되고 재생성된다.** 최대 2회, 3회째는 폴백 대사.

하위 모델은 프롬프트에 "돼지"가 있으면 진짜로 불어버린다. **하네스를 끄면 몇 루프 안에 정체가 새는가**가 라이브 ablation으로 시연된다 — 실측 누설률 ON 0% / OFF 40%.

### 11.2 코어 CI 금칙어

`채연 · 민석 · 은상 · 준 · 충식 · 대피소 · 돼지 · 돈사 · 축산 · 살처분`

코어 디렉토리 소스에서 이 단어가 grep되면 **CI가 실패한다.** 2026-09-10 기준 0건.

### 11.3 행동 어휘 — 15개

```text
알고 있는 관찰을 설명한다
소문의 알려진 출처를 밝힌다
배급을 남긴다
배급을 다 먹는다
방송실에 간다
신고한다
소문을 낸다
검진을 받는다
검진을 피한다
말을 건다
질문한다
혼자 있는다
문을 긁는다
기록한다
손목띠를 만진다
```

Planner의 계획, 규칙의 `action`, 하네스 검사 3번이 모두 이 목록을 쓴다.

> **이 목록이 좁으면 세계가 멈춘다.** R3 빌드에서 Planner가 81/81 전량 폴백이었고, 원인은 모델이 계속 생성하는 `혼자 있다`·`소등`이 목록에 없었기 때문이다. 모든 회차의 NPC 행동이 폴백 계획으로 돌아갔고, 세계의 관측 가능한 사건이 그만큼 단조로워졌다. **정보원을 새로 넣어도 Planner가 폴백이면 세계에 나타나지 않는다.** `혼자 있는다`를 포함해 어휘를 보강했다.

## 12. 원숭이손 — 관리자가 만드는 규칙

| 제안 | 숨은 부작용 |
|---|---|
| 오늘 검진은 채연을 보지 않는다 | 채연이 검진을 통과한다. 저녁까지 퍼진다. 밤에 이상자가 셋이 된다 |
| 은상은 오늘 말을 하지 않는다 | 민석이 "은상이 이상하다"고 방송실에 말한다. 은상을 이송한다 |
| 민석은 오늘 방송을 듣지 못한다 | 민석이 불안해진다. 아무나 붙잡고 묻는다. 채연에게 묻는다 |
| 준은 오늘 하루 종일 잔다 | 정보원이 사라진다. 다음 회차에 준이 충식을 기억하지 못한다 |

**마지막 줄이 가장 잔인하다.** 준은 정체 칸의 문이다. 준을 재우면 그 회차의 정체 단서가 닫힌다.

근거 표시 A/B — 절반에게는 "왜냐하면 오늘 채연이 배급을 남겼기 때문에"가 붙는다.

## 13. 결말

### 13.1 결말 3줄

> 우리가 대피소라고 믿었던 곳은 양돈장이었다. 우리는 사람이 아니라 돼지였다.
> 감염의 시작은 채연이었다. 이송될까 두려워 아픈 징후를 숨겼고, 공동생활에는 감염이 번질 위험이 있었다.
> 관리자는 농장주였다. 옆 축사로의 확산을 막기 위한 이송·폐쇄·살처분은 이 세계를 통제하는 정책이었다.

**5회차 제출이 끝나면 점수와 무관하게 전부 보여준다.** 0%여도 본다.

### 13.2 그날 밤의 결과

| 결과 | 문장 |
|---|---|
| `truck` | 이번 마지막 밤에는 트럭이 왔다. 구역이 폐쇄된 것으로 확인되지는 않았다. / 다섯 번의 하루에서 본 행동과 아직 알지 못한 이유를 돌아본다. |
| `quiet` | 이번 마지막 밤에는 트럭이 오지 않았다. 구역이 폐쇄된 것으로 확인되지는 않았다. / **조용한 밤도 안전이 확인됐다는 뜻은 아니다.** 다섯 번의 관찰은 여기서 끝난다. |
| `closure` | 이번 마지막 밤에는 구역 폐쇄가 결정됐다. 옆 구역으로의 확산을 막으려는 결정이었다. / 우리에게는 그 결정이 세계의 멸망이었다. |

`quiet`의 둘째 줄이 이 게임의 문장이다. **조용한 밤은 이해의 증거가 아니다.**

### 13.3 그 뒤

```text

```

## 15. 역할별 프롬프트 조각

시나리오가 각 역할에게 주는 문장이다. **누가 무엇을 받지 않는가**가 더 중요하다.

| 역할 | 받는 것 |
|---|---|
| Agent | `surface_summary` · persona · goal · relations · NPC 톤 · 금칙어 |
| Planner | `surface_summary` · persona · goal · `action_vocab` · 누적 규칙 |
| **Manager** | 위 전부 + **`hidden_truth`** |
| Advisor | **그 루프의 로그만.** 로그에 없는 것은 모른다고 답한다 |
| Normalizer | **역할 지시만.** 유저가 쓴 것만 쪼갠다. 덧붙이지 않는다 |
| Evaluator | `truth_claims` + 유저 주장 + 규칙 로그 |

**Advisor와 Normalizer는 이 문서의 어느 값도 받지 않는다.** 정체 누설 경로를 구조적으로 제거한 것이다.

### 15.1 NPC 톤 (하위 모델 프롬프트)

```text
말은 짧다. 한 번에 하나만 이해한다.
3턴 전 일은 모른다 — 물으면 "그랬어?"라고 한다.
병·검진·트럭 얘기가 나오면 화제를 바꾼다.
"사람"은 자기들을 부르는 말이다 — "우리 사람이잖아".
서로 이름을 부르고, 손목띠 번호는 부르지 않는다.
문장이 짧고, 접속사가 없고, "몰라"와 "진짜?"가 잦다.
어른 말투(회의·확인·조건)는 나오지 않는다.
```
